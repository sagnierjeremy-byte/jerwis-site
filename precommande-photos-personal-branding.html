— Installation en 3 minutes · sans toucher au code

Pas dev ?
Tu t'en sors quand même.

Le tunnel a été pensé pour que tu n'aies jamais à ouvrir un fichier de configuration. Stripe → Vercel → 3 clés API collées dans l'UI. Si l'app dit vert, c'est que ça marche.

01

Tu paies sur Stripe

Carte bancaire, 2 minutes. Tu reçois le ZIP + l'invitation au repo GitHub privé par email dans la foulée.

02

Tu deploy sur Vercel

Bouton « Import » sur Vercel, tu pointes ton repo (ou tu drop le ZIP), tu cliques deploy. Plan Hobby gratuit, aucun fichier à éditer.

03

Tu colles 3 clés dans Paramètres

FAL_KEY, OPENROUTER_API_KEY, ADMIN_TOKEN dans le dashboard Vercel. Tu rouvre /settings dans l'app, tu clique « Tester la connexion ». Vert → tu génères ta première photo.
