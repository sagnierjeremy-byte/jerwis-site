Tu cherches par thème ?

Si tu sais déjà ce qui t'intéresse, attaque par là. Sinon, prends d'abord les 30 essentiels ou descends à l'index A-Z plus bas.

A

  • Agent Un agent, c'est une IA qui ne se contente pas de répondre : elle décide elle-même des étapes à enchaîner et appelle des outils. Tu le croises dans les workflows complexes. Définition express
  • Agent goal hijack Une instruction cachée dans une page web ou un email détourne ton agent de ce que tu lui as demandé. Le piège des agents qui lisent du contenu externe. Définition express
  • Agent graph La carte des étapes que ton agent enchaîne, avec des chemins différents selon ce qu'il décide à chaque étape. Définition express
  • Agent vocal Un agent qui écoute, comprend et répond à la voix, parfois en déclenchant des actions pendant la conversation. Tu le croises sur les hotlines IA. Page détaillée
  • AGENTS.md Un fichier d'instructions posé à la racine d'un projet. L'agent IA le lit en premier pour respecter les règles du projet. Définition express
  • Aggregator Brique d'automatisation qui regroupe plusieurs éléments traités séparément pour reconstituer une liste, un rapport ou un lot final. Tu le croises après un iterator dans n8n ou Make. Définition express
  • AGI / ASI AGI = IA aussi polyvalente qu'un humain. ASI = IA qui nous dépasse largement. Tu l'entends dans les débats sur la trajectoire longue de l'intelligence artificielle. Page détaillée
  • AI Agent node n8n Le AI Agent node n8n donne à une automatisation un agent capable de choisir des outils selon la demande. Définition express
  • Allowlist / Denylist Une allowlist autorise seulement ce qui est prévu, une denylist bloque ce qui est risqué. Tu les vois pour limiter les commandes shell, les domaines web ou les serveurs MCP accessibles. Définition express
  • Annotation d'outil Une annotation d'outil ajoute des indications sur le comportement, le risque ou l'usage prévu d'un outil d'agent. Définition express
  • API compatible OpenAI Tu gardes ton code, tu changes juste le fournisseur — Mistral, Groq, vLLM, etc. Définition express
  • Approval gate Un approval gate bloque une action jusqu'à validation humaine ou règle explicite. Définition express

B

  • Base de connaissances Une base de connaissances est le dossier organisé dans lequel l'IA va chercher avant de répondre. Tu la croises dans les assistants documentaires, Notion AI ou les chatbots branchés sur tes docs. Définition express
  • Base vectorielle Une base qui stocke des embeddings et retrouve les textes les plus proches d'une question. Le moteur des chatbots qui répondent sur tes documents. Page détaillée
  • Batch API Une Batch API lance beaucoup de requêtes IA en différé pour payer moins cher ou traiter un gros volume sans bloquer l'interface. Définition express
  • BM25 Une vieille méthode de recherche par mots exacts (comme Google avant l'IA). Utile quand un mot précis doit absolument apparaître. Tu le croises dans les moteurs full-text et la recherche hybride. Définition express
  • Bolt.new Builder d'app web full-stack avec IA. Tu décris, ça code, ça déploie en 1 clic. Tu le croises pour prototyper une app SaaS sans toucher au terminal. Page détaillée
  • Boucle d'outils Une boucle d'outils alterne réflexion de l'IA, appel d'outil, résultat, puis nouvelle étape. Définition express
  • Branch Une branch est une ligne de travail séparée de la version principale. Tu la vois sur GitHub quand un changement est préparé sans toucher à la prod. Définition express
  • Browser Use Browser Use est un framework et cloud pour faire accomplir des tâches web à un agent IA. Définition express

C

  • Chain of thought Le modèle réfléchit étape par étape avant de répondre, comme s'il pensait à voix haute. Utile sur les sujets de logique ou de calcul. Page détaillée
  • ChatGPT Atlas L'agent navigateur d'OpenAI (Operator). Pilote ton browser pour toi : remplir des forms, scraper, acheter. Tu le croises dès que tu veux déléguer une tâche web répétitive. Page détaillée
  • Checkpoint Un checkpoint sauvegarde l'état d'un agent pour reprendre proprement plus tard. Tu le croises dans LangGraph, les agents long-cours et les workflows interruptibles. Définition express
  • Chunk overlap Le chunk overlap garde une petite zone commune entre deux morceaux de document pour éviter de couper une idée au mauvais endroit. Définition express
  • Chunking Découper tes documents en petits morceaux avant de les indexer. Garantie que l'IA retrouvera le bon passage sans noyer son contexte. Page détaillée
  • Citations de sources Les citations montrent précisément d'où vient une réponse pour que je puisse vérifier. Définition express
  • Claude Code Claude Code est l'agent de Claude qui lit un projet, modifie des fichiers et lance des commandes avec ton accord. Page détaillée
  • Claude Haiku 4.5 Petit Claude rapide. Pour les classifications, extractions, chatbots à fort volume. Tu le croises dès que tu pousses du volume sans budget illimité. Page détaillée
  • Claude Opus 4.7 Le frontier d'Anthropic. Pour les tâches où je ne peux pas me permettre une erreur — rédaction longue, raisonnement nuancé. Tu le croises quand le résultat compte plus que le coût. Page détaillée
  • Claude Sonnet 4.6 Mon modèle par défaut chez Anthropic. Le meilleur équilibre prix/qualité pour CRM, agents et contenus pro. Tu le croises quand tu veux un Claude qui réfléchit bien sans payer Opus. Page détaillée
  • CLAUDE.md CLAUDE.md est le fichier où tu notes les règles du projet pour que Claude ne reparte pas de zéro. Page détaillée
  • Clé API Une clé API est un mot de passe technique qui autorise un outil à appeler un service d'IA en ton nom. Tu la croises dans les consoles Anthropic, OpenAI, Resend, Supabase ou les champs de connexion no-code. Page détaillée
  • CLI / Terminal La CLI est une interface où tu écris des commandes au clavier au lieu de cliquer dans une application. Tu la rencontres pour lancer Codex CLI, installer un outil, publier un site ou exécuter un script. Définition express
  • Clonage de voix Le clonage de voix recrée une voix à partir d'échantillons audio. Tu le croises dans ElevenLabs, les voix de podcast, les agents vocaux et les démos de deepfake audio. Définition express
  • Code Interpreter Sandbox où l'IA écrit et exécute du code Python isolé. Aussi appelé Advanced Data Analysis (OpenAI) ou tool « python » chez Claude. Pas d'accès réseau par défaut. Tu le croises quand tu demandes à ChatGPT d'analyser un CSV ou de tracer un graphe. Page détaillée
  • Codex CLI Codex CLI est l'interface locale qui permet à Codex de lire un projet, proposer des changements et lancer des commandes. Tu la croises dans le terminal des devs qui pair-codent avec OpenAI. Définition express
  • Codex web Codex web est l'interface navigateur pour suivre ou lancer des tâches Codex sans rester dans le terminal. Définition express
  • Commit Un commit est une sauvegarde nommée dans l'historique Git. Tu le vois à chaque fois qu'un changement est validé dans un projet code. Définition express
  • Compression contextuelle La compression contextuelle réduit les passages retrouvés pour garder seulement les morceaux utiles à la question. Tu la croises dans les RAG avancés qui doivent tenir dans une fenêtre de contexte serrée. Définition express
  • Computer use Capacité de certains modèles (Claude, GPT-5.5 agent mode) à voir l'écran via screenshots et piloter souris/clavier comme un humain. Tu la croises dans ChatGPT Atlas, Claude Computer Use et les agents qui automatisent un browser. Page détaillée
  • Confused deputy Un agent autorisé se fait manipuler pour faire un truc que l'attaquant, lui, n'a pas le droit de faire. Définition express
  • Connecteur de données Un connecteur de données va chercher les informations là où elles vivent déjà. Tu le croises dans n8n, Make, Zapier ou les agents reliés à Gmail, Notion, Drive. Définition express
  • Context engineering Donner au modèle juste ce qu'il faut, au bon moment : règles, docs, exemples, outils. Tu le pratiques dans Claude Code, Codex et tous les agents sérieux qui doivent rester focus sans s'encombrer. Page détaillée
  • Context poisoning Le context poisoning injecte une donnée trompeuse dans le contexte donné au modèle pour orienter sa réponse ou ses actions. Tu le croises dans les attaques contre les agents qui lisent des pages web ou des documents externes. Définition express
  • Context precision La context precision mesure si les passages donnés au modèle sont vraiment utiles pour répondre à la question. Définition express
  • Context recall Le context recall mesure si le système a bien retrouvé tous les passages nécessaires pour répondre correctement. Définition express
  • Credentials n8n Les credentials n8n stockent les accès à tes outils pour éviter de recopier les clés partout. Définition express
  • Cron Job Vercel Un Cron Job Vercel lance une tâche à heure fixe, comme une veille ou une mise à jour de données. Tu le croises dans les newsletters automatiques et les pipelines de scraping. Définition express
  • Cross-encoder Un deuxième filtre plus malin qui relit les meilleurs résultats trouvés pour ne garder que les vraiment pertinents. Tu le croises dans les rerankers, moteurs RAG avancés et systèmes où la qualité de classement compte plus que la vitesse. Définition express
  • Cursor L'IDE IA leader pour devs en 2026. Fork VS Code avec Claude/GPT intégrés en pair-programming. Tu le croises dès que tu touches au code accompagné par une IA. Page détaillée
  • Cursor Rules Les Cursor Rules sont des instructions persistantes qui cadrent le comportement de Cursor dans un projet. Tu les croises dans les projets Cursor, conventions de code et règles d'équipe. Définition express
  • Custom GPT ChatGPT personnalisé avec ses consignes, fichiers et actions. Spécifique à OpenAI. Équivalents : Claude Skills/Apps, Gemini Gems. Page détaillée

D

  • Deep Research Deep Research lance une recherche longue, cite ses sources et rend un rapport structuré. Tu le croises dans ChatGPT, Gemini, Perplexity quand tu veux un mémo sourcé. Page détaillée
  • Deepfake Un deepfake est un contenu synthétique qui imite une personne réelle, souvent en image, voix ou vidéo. Tu le croises dans les débats sur clonage vocal, avatars, fraude et vérification de contenus. Définition express
  • DeepSeek R1 Le reasoning open-weight de DeepSeek. Concurrent direct de GPT-5 thinking, gratuit en poids. Tu le croises quand tu veux du raisonnement avancé sans dépendre d'une API US. Page détaillée
  • DeepSeek V3.2 Le frontier open-weight le moins cher du monde. 10× moins cher que Claude Sonnet. Tu le croises quand tu pousses du volume ou tu veux self-host. Page détaillée
  • Deployment Protection Vercel Deployment Protection Vercel contrôle qui peut accéder à un déploiement preview ou production. Définition express
  • Détection d'activité vocale La détection d'activité vocale repère quand une personne commence ou arrête de parler. Tu la croises dans les agents vocaux, Realtime API et les interfaces audio à faible latence. Définition express
  • Diarisation locuteur La diarisation locuteur sépare une transcription selon les personnes qui parlent. Tu la croises dans les comptes rendus de réunion, podcasts, appels clients et interviews. Définition express
  • Distillation On entraîne un petit modèle à imiter un gros. Technique principale derrière les variantes « mini », « haiku », « flash » de chaque famille. Tu la croises chaque fois qu'un fournisseur sort une version plus rapide et moins chère d'un modèle frontier. Page détaillée
  • Document Intelligence Document Intelligence analyse texte, mise en page, tableaux, champs et structure d'un document. Tu la croises dans Azure Document Intelligence, Mistral OCR, extraction de factures et RAG documentaire. Définition express
  • Durable execution Une automatisation qui sait reprendre là où elle s'est arrêtée si elle plante ou attend ta validation, même 3 jours plus tard. Définition express

E

  • Edge Function Supabase Une Edge Function Supabase lance du code serveur pour connecter une app à des API ou traiter une action sensible. Définition express
  • ElevenLabs v3 Référence TTS multilingue. C'est ce que j'utilise pour les voix du podcast Jerwis Productions. Tu le croises dès que tu veux une voix IA crédible en français. Page détaillée
  • Elicitation MCP Quand un outil branché à ton IA lui demande de te poser une question (ex. : « quel client ? ») avant de continuer. Tu la croises quand un MCP doit demander une précision avant d'agir. Définition express
  • Embedding Une façon pour l'IA de mesurer si deux textes parlent de la même chose, même avec des mots différents. C'est la brique de base de toute recherche intelligente. Tu le croises dans le RAG, la recherche sémantique et les bases vectorielles. Page détaillée
  • Embedding intégré Quand la base de données fabrique elle-même la « signature » du texte, sans que tu aies à le faire toi-même. Tu le croises dans les bases vectorielles qui simplifient les pipelines RAG. Définition express
  • Embedding multimodal Un embedding qui range texte, image, audio et vidéo dans le même espace, pour les comparer entre eux. Tu le croises dans la recherche texte-vers-image, les catalogues produits et le RAG multimodal. Définition express
  • Endpoint API L'adresse web précise (genre URL) qu'un programme tape pour parler à un service. Comme un numéro de téléphone direct vers une fonction. Tu le croises dans les docs OpenAI, Anthropic, Supabase et les webhooks no-code. Définition express
  • Entité Une entité est un élément identifiable dans un texte : personne, entreprise, lieu, produit, contrat, date ou concept. Tu la croises dans l'extraction d'informations, les graphes de connaissances et GraphRAG. Définition express
  • Entity linking L'entity linking rattache une mention trouvée dans un texte à la bonne entité de référence. Tu le croises quand un système doit comprendre que deux variantes de nom désignent la même entreprise. Définition express
  • Évaluation / Eval Mesurer si ton IA répond comme tu veux sur un jeu de cas réels. Sans eval, tu navigues à vue. Définition express
  • Evaluator-optimizer Evaluator-optimizer est une boucle où une sortie est produite, évaluée, puis améliorée. Définition express
  • Excessive agency L'excessive agency arrive quand un agent a trop d'autonomie, trop d'outils ou trop de droits. Tu la croises dans les discussions OWASP et les agents capables d'envoyer, supprimer ou publier. Définition express
  • Expression n8n Une expression n8n insère une valeur dynamique ou une formule dans un champ de workflow. Définition express
  • Extraction d'entités L'extraction d'entités repère automatiquement les noms, dates, organisations ou montants dans un texte. Tu la croises dans la lecture de contrats, factures et fiches CRM. Définition express
  • Extraction de relations L'extraction de relations identifie les liens entre entités, par exemple qui possède quoi, qui travaille avec qui ou quel document cite quel contrat. Définition express
  • Extraction structurée L'extraction structurée demande à l'IA de sortir des champs propres depuis un document. Définition express

F

  • Faithfulness Note qui dit si l'IA est restée collée aux documents qu'on lui a donnés, ou si elle a inventé des trucs à côté. Définition express
  • Fenêtre de contexte C'est la quantité de texte que le modèle peut ingurgiter d'un coup. 200 k chez Claude, 1 M chez Gemini en 2026. Attention : la qualité dégrade au milieu, donc 1 M tokens ne veut pas dire 1 M utilisés efficacement. Page détaillée
  • Few-shot / Zero-shot Zero-shot signifie demander sans exemple. Few-shot signifie donner quelques exemples avant la demande. Page détaillée
  • Fichier .env Un fichier .env range les clés et réglages sensibles d'un projet hors du code visible. Tu le vois à la racine d'un projet, ignoré par Git. Page détaillée
  • File Search tool File Search permet au modèle de chercher dans tes fichiers avant de répondre. Tu le croises dans l'API OpenAI Responses et les assistants documentaires. Définition express
  • Filtre de métadonnées Un filtre de métadonnées limite la recherche à certains documents selon leur source, date, client, langue, type ou statut. Définition express
  • Fine-tuning Ré-entraîner un modèle existant sur mes exemples pour qu'il colle à mon usage. Je n'y vais que si le prompt + RAG n'ont pas suffi — c'est plus cher et moins flexible. Page détaillée
  • Flux Famille de modèles image Black Forest Labs (ex-Stability). Alternative open à Midjourney. Tu le croises dans ComfyUI et les workflows image self-hosted. Page détaillée
  • Fournisseur de modèle Le fournisseur de modèle est la plateforme qui donne accès au modèle que tu utilises. Tu le croises quand tu choisis entre OpenAI, Anthropic, Google, Mistral ou OpenRouter. Définition express

G

  • Gemini 2.5 Flash Le couteau suisse pas cher de Google. Multimodal natif à 0,30 $/Mtok. Tu le croises dès que tu pousses du volume image+texte avec un budget serré. Page détaillée
  • Gemini 3.1 Pro Le haut de gamme de Google. Excellent en multimodal natif (image+audio+vidéo dans un seul appel). Tu le croises dès que ta tâche mixe plusieurs médias. Page détaillée
  • Génération vidéo La génération vidéo crée ou prolonge une séquence vidéo avec un modèle génératif. Définition express
  • Genspark Agent recherche/synthèse multi-sources. Concurrent direct de Perplexity. Tu le croises quand tu veux comparer plusieurs angles sur un sujet rapidement. Page détaillée
  • Git Git garde l'historique des changements d'un projet et permet de revenir en arrière. Tu le croises dans tout projet code, GitHub, GitLab, Codex et Claude Code. Définition express
  • GitHub Actions GitHub Actions lance automatiquement des tâches quand quelque chose arrive dans un repo. Tu le croises pour les tests, déploiements et notifications déclenchées par un push. Page détaillée
  • Golden dataset Un golden dataset est un jeu d'exemples validés qui sert de référence pour tester prompts, modèles ou workflows IA. Définition express
  • GPT-5 Le frontier OpenAI sorti en 2025. Toujours en service, comparable à Sonnet 4.6 sur 95 % des usages. Tu le croises dans ChatGPT Plus et l'API OpenAI. Page détaillée

  • Graphe de connaissances Un graphe de connaissances relie des entités entre elles pour représenter qui est lié à quoi dans un corpus. Tu le croises dans GraphRAG, les bases métier complexes et les assistants qui doivent comprendre les relations. Définition express
  • GraphRAG Version du RAG qui ne se contente pas de retrouver des passages mais comprend aussi les liens entre les infos (qui connaît qui, quoi cause quoi). Tu la croises dans Microsoft GraphRAG et les analyses de gros corpus documentaires. Page détaillée

  • Grounding Le grounding force le modèle à s'appuyer sur des sources réelles plutôt qu'à inventer. Tu le croises dans les réponses avec citations, les recherches web augmentées et les chatbots documentaires. Définition express
  • Guardrail Un guardrail est une règle de sécurité qui limite ce qu'une IA ou un agent peut faire. Tu le croises dans les assistants en prod, NeMo Guardrails, Bedrock Guardrails. Page détaillée

H

  • Hallucination Quand l'IA invente une info présentée avec assurance. Le piège classique : tu lui demandes une source, elle te file une URL inexistante. Je vérifie toujours les chiffres et les noms. Tu la rencontres surtout sur les citations, dates, statistiques et fonctions techniques. Page détaillée
  • Handoff Un handoff est le passage d'une tâche d'un agent à un autre agent plus adapté. Tu le croises dans les systèmes avec agent d'accueil, agent recherche, agent rédaction ou agent support. Définition express
  • HNSW Une technique pour retrouver des résultats similaires très vite dans une grosse base, sans tout comparer un par un. Définition express
  • Hook Un hook déclenche une action automatique avant ou après certains gestes de l'agent. Tu le croises dans Claude Code et les outils qui veulent contrôler chaque étape. Page détaillée
  • Hugging Face Hub Hugging Face Hub est la plateforme où sont publiés modèles, datasets, Spaces et fichiers liés à l'IA open. Tu le croises quand tu cherches un modèle ouvert, une démo ou une carte de modèle. Définition express
  • Human-in-the-loop Tu mets un humain entre les étapes d'un agent pour valider avant de continuer. Sécurité de base pour les actions sensibles. Page détaillée

I

  • ID de modèle L'ID de modèle est le nom exact à mettre dans un outil ou une API pour choisir le moteur qui répond. Tu le croises dans les API OpenAI, Claude, Gemini, Vercel AI SDK ou les réglages d'un agent. Définition express
  • Imagen 4 Génération photo réaliste premium chez Google. Ultra rivalise avec Midjourney v7. Tu le croises dans Gemini et Vertex AI quand tu veux du réalisme photo. Page détaillée
  • Indexation documentaire L'indexation prépare les morceaux de documents pour qu'une recherche puisse les retrouver vite. Tu la croises dans les bases vectorielles, Azure AI Search et les pipelines RAG. Définition express
  • Indexation incrémentale L'indexation incrémentale ajoute ou met à jour seulement les documents modifiés au lieu de reconstruire toute la base. Définition express
  • Indirect prompt injection Une indirect prompt injection cache des instructions malveillantes dans un contenu que l'agent lit. Tu la croises dans les risques liés aux agents qui lisent pages web, emails, documents ou tickets support. Page détaillée
  • Inférence L'inférence est le moment où le modèle produit une réponse à partir de ta demande. C'est ce que tu paies à chaque appel API. Tu la croises dans toutes les tarifications IA, exprimées en tokens d'entrée et de sortie. Page détaillée
  • Ingestion de documents L'ingestion importe des documents pour les nettoyer, les découper et les rendre cherchables. Tu la croises quand tu branches des PDF, pages web, dossiers Drive ou bases Notion dans un système RAG. Définition express
  • Ingestion Pipeline Un ingestion pipeline enchaîne découpage, extraction de métadonnées, embeddings et stockage. Définition express
  • Inpainting L'inpainting remplace ou corrige une zone précise d'une image avec une génération IA. Tu le croises dans Photoshop Generative Fill, Nano Banana et les éditeurs photo IA. Définition express
  • Interrupt Un interrupt met l'agent en pause le temps qu'une personne valide, corrige ou complète. Définition express
  • Isolation de contexte L'isolation de contexte sépare les instructions fiables, les données utilisateur et les contenus externes pour éviter les mélanges dangereux. Tu la croises dans les agents sérieux qui lisent du contenu venu du web. Définition express
  • Issue GitHub Une issue GitHub est une demande de travail structurée que tu peux confier à une personne ou à un agent. Tu la croises sur n'importe quel projet open source ou repo d'équipe. Définition express
  • Iterator Un iterator prend une liste et la transforme en éléments traités un par un. Tu le croises dans Make et n8n pour boucler sur des emails, lignes ou contacts. Définition express
  • IVFFlat Autre méthode pour accélérer la recherche dans une base IA : range les documents par paquets pour ne fouiller que les paquets utiles. Définition express

J

  • Jailbreak Un jailbreak cherche à contourner les règles de sécurité d'un modèle. Tu l'entends surtout dans les discussions de sécurité IA et les tests de robustesse. Page détaillée
  • Journal d'appels d'outils Un journal d'appels d'outils conserve les actions demandées par un agent, les paramètres envoyés et les résultats obtenus. Définition express

K

  • Kling Le meilleur générateur vidéo IA en 2026 selon la communauté créa. Tu le croises dès que tu veux des plans cinématographiques à partir d'une image ou d'un texte. Page détaillée

L

  • Late interaction Méthode qui fait deux passes : une rapide, puis une plus fine sur le top des candidats. ColBERT en est l'archétype. Définition express
  • Latence La latence est le délai total ressenti entre ta demande et la réponse. Tu la vois dans les agents temps réel, le voice, les démos de modèles rapides. Page détaillée

Deepfake

Où tu le croises : Tu le vois dans les débats sur clonage vocal, avatars, fraude, identité numérique et vérification des contenus.

Navigateur headless
