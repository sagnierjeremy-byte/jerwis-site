Claude Code,
le guide complet.

Salut, moi c'est Jérémy. Je ne suis ni développeur ni codeur, je suis un entrepreneur qui utilise Claude Code tous les jours. Ici, je rassemble tout ce que tu dois savoir : ce que c'est, pourquoi ça change la donne, comment ça se compare à Cursor ou Codex, comment le démarrer dans l'app Claude, sur Mac et Windows, et les workflows qui m'ont vraiment servi.

— Définition

Qu'est-ce que
Claude Code ?

En une phrase

Claude Code est l'agent de code d'Anthropic, qui transforme l'IA Claude en agent capable de lire, écrire et exécuter du code directement sur ton ordinateur. Tu le trouves dans l'onglet Code de l'app Claude, sur Mac et Windows. Au lieu de copier-coller du code depuis un chat, tu lui parles en français, et il agit dans tes fichiers, lance des scripts, lit ton codebase, teste, corrige.

Concrètement, tu ouvres l'app Claude, tu cliques sur l'onglet Code, tu choisis un dossier de ton ordinateur, et tu te retrouves dans une session où Claude Code peut faire ce qu'un assistant humain ferait à ta place : ouvrir un fichier, le modifier, lancer un test, valider, recommencer. Tu peux lui dire « Ajoute un formulaire d'inscription à ma page, connecte-le à Resend, teste que ça marche », et il enchaîne les étapes tout seul.

Claude Code vs Claude.ai (le chat)

Le chat, c'est la conversation. Tu poses des questions, Claude répond du texte. Claude Code, c'est l'exécution. Tu donnes une intention, Claude lit ton projet, manipule des fichiers, exécute des commandes, et te livre un résultat. C'est la même IA derrière (les modèles Opus, Sonnet et Fable d'Anthropic), et les deux vivent dans la même app, mais l'onglet change tout. Dans le chat tu copies-colles du code à la main ; avec Claude Code tu ne touches plus jamais à un clavier de programmation.

Claude Code vs Cursor, Aider, Codex et GitHub Copilot

Tous ces outils utilisent une IA pour écrire du code. La différence se joue sur trois axes : où ça vit (une app, un éditeur ou la ligne de commande), qui agit (toi vs l'agent), et le modèle derrière (Claude vs GPT vs autres). Cursor est un éditeur de code complet avec un chat ; Aider est un outil open-source en ligne de commande qui modifie des fichiers ; GitHub Copilot est un autocomplete intégré dans VS Code ; Codex est l'agent de code d'OpenAI. Claude Code combine la simplicité d'Aider, l'agentivité de Codex, et la qualité de raisonnement de Claude.

Tu trouveras le tableau de comparaison détaillé un peu plus bas sur cette page. Si tu veux le résumé : prends Cursor si tu veux remplacer VS Code, prends Claude Code si tu veux déléguer des tâches entières à un agent autonome.

Pour qui c'est fait ?

Officiellement, c'est un outil pour développeurs. Dans les faits, j'utilise Claude Code tous les jours sans être développeur. Si tu sais installer une app et écrire en français ce que tu veux, tu peux l'utiliser. Je connais des consultants qui s'en servent pour générer des rapports clients, des marketeurs qui montent leurs landing pages sans dev, des avocats qui automatisent la relecture de contrats. Le ticket d'entrée est plus bas que ce que les gens pensent.

Tout commence dans l'app Claude

Anthropic a sorti en avril 2026 une application Claude Desktop (Mac + Windows) avec un onglet Code intégré, zéro commande à taper. C'est par là que ce guide te fait démarrer, à l'étape 01, avant le CLAUDE.md et les skills. La version terminal existe toujours, je la garde pour les curieux dans l'annexe, tout en bas.

— Le shift

Pourquoi Claude Code
change tout.

L'idée centrale

Avec Claude Code, l'IA n'est plus un assistant qui suggère, c'est un agent qui exécute. C'est le passage du copilote au pilote automatique sous contrôle. Tu donnes une intention, Claude la décompose, lance les bons outils, vérifie le résultat, te rend un travail livré.

Pendant des années, l'IA pour le code, c'était de l'autocomplete : tu tapes une fonction, l'IA propose la suite, tu valides. Utile, mais tu restes le pilote. Claude Code casse ce schéma. Tu lui décris ce que tu veux obtenir, il choisit lui-même les fichiers à toucher, les commandes à lancer, les tests à faire. Tu redeviens le décideur, pas l'exécutant. C'est ce que j'appelle un workflow agentique.

Ce que ça change pour moi, concrètement

J'ai monté ce site sans écrire une ligne de HTML moi-même. J'ai construit un outil de vente qui me sert au quotidien. J'ai un Hermes Agent qui m'envoie automatiquement des messages Telegram quand mes builds passent. J'ai lancé un agent Gmail qui filtre mes emails. Tout ça, c'est Claude Code qui l'a construit, et qui le maintient.

Les vraies forces de Claude Code

  • Il lit ton codebase entier. Avec 1 million de tokens de contexte sur Opus 5.5, il peut tenir tout un projet en tête avant d'agir.
  • Il lance des sous-agents en parallèle. Tu lui demandes d'analyser cinq documents, il en lance cinq simultanément, puis synthétise. Cinq fois plus rapide qu'un agent séquentiel.
  • Il s'intègre avec MCP. Tu peux brancher Sanity, Stripe, Telegram, ta base Postgres, ton compte Meta Ads — tout via le standard ouvert MCP.
  • Il se contrôle finement. Avec les hooks et le CLAUDE.md, tu peux empêcher Claude de toucher à certains fichiers, lui imposer des règles, déclencher des actions à des moments précis.

Ce que Claude Code fait moins bien (l'honnêteté)

Je ne vais pas te vendre Claude Code comme la solution miracle. Voici ce qu'il fait moins bien dans mon expérience : il invente parfois des fonctions de librairies qui n'existent pas (le plugin context7 règle 80 % du problème en lui donnant la doc à jour). Il sur-écrit le code en ajoutant des commentaires inutiles (le skill code-simplifier nettoie). Il perd parfois le fil sur des sessions très longues (au-delà de 500 000 tokens, je préfère ouvrir une nouvelle session). Et il ne remplace pas un vrai dev senior pour des décisions d'architecture critiques — pour ça, je demande l'avis d'un humain.

Mes cas d'usage récurrents

  • Je lui demande d'écrire mes newsletters en respectant mon ton (skill copywriting)
  • Je lui demande de construire des pages web comme celle-ci (skill landing-page-generator)
  • Je lui fais auditer la sécurité de mes projets (skill security-review)
  • Je lui fais faire de la veille (skill deep-research)
  • Je lui fais écrire et envoyer des cold emails (skill cold-email)
  • Je lui fais traiter mes audios de podcast et générer les transcripts
  • Je lui fais surveiller mes builds Vercel et m'alerter quand il y a une régression

Tout ça, c'est des skills. On verra comment les installer à l'étape 04 plus bas.

— Étape 01

Installer l'app Claude.
Tout part de là.

Claude Code vit dans l'app Claude, sur Mac et sur Windows. Aucune commande à copier, rien d'autre à installer : l'app contient déjà Claude Code. Tu télécharges, tu te connectes, tu cliques sur l'onglet Code.

Il te faut un abonnement payant

Claude Code n'est pas dans l'offre gratuite de Claude. Il est inclus dans Pro (20 $ par mois hors taxes, ou 17 $ par mois en annuel), dans Max (à partir de 100 $ par mois), et dans les offres Team et Enterprise. Si tu cliques sur Code sans abonnement, l'app te propose de passer à une offre payante.

01

Télécharge l'app

Va sur claude.com/download et choisis ta version. Sur Mac, c'est la même pour les puces Intel et Apple. Sur Windows, il y a une version classique et une version pour les PC à processeur ARM.

02

Installe-la et connecte-toi

Sur Mac, ouvre le fichier téléchargé et range Claude dans ton dossier Applications. Sur Windows, lance l'installeur. Ouvre l'app et connecte-toi avec ton compte Claude, celui de ton abonnement.

03

Clique sur l'onglet Code

Il est en haut de la barre latérale de l'app. Si les onglets n'affichent que des icônes, passe la souris dessus pour voir leur nom. Si l'app te demande de te reconnecter en ligne, fais-le, puis redémarre l'app.

C'est installé.

L'onglet Code, c'est Claude Code. Tout le reste de ce guide (ta première session, le CLAUDE.md, les skills, les plugins) se fait depuis là.

— Étape 02

Ta première session.

Une session, c'est une conversation avec Claude sur un dossier de ton ordinateur. Claude travaille dans le dossier que tu lui donnes. Commence par un petit dossier de test, c'est la façon la plus rapide de voir ce qu'il sait faire.

01

Crée un dossier de test

Sur ton bureau, fais un clic droit et crée un nouveau dossier vide. Appelle-le test-claude.

02

Ouvre-le dans l'onglet Code

Regarde la ligne juste sous la zone de message. Le premier bouton choisit où Claude travaille, garde ton ordinateur (le groupe Local). Le bouton d'à côté choisit le dossier. Clique dessus, choisis d'ouvrir un dossier et sélectionne test-claude.

03

Choisis ton modèle et ton mode

Au bout de la même ligne, le sélecteur de modèle. Prends Opus 5.5, celui qu'Anthropic conseille pour commencer. Juste avant, le sélecteur de mode règle ce que Claude peut faire sans te demander. Pour débuter, garde le mode manuel : Claude te montre chaque modification et attend ton accord.

04

Écris ton premier message

Tape dans la zone de message, puis Entrée : « Crée-moi un fichier hello.txt avec "Hello world" dedans ». Claude te montre le fichier qu'il veut créer. Accepte, puis ouvre ton dossier, hello.txt est là.

Ensuite, essaie : « Fais-moi une page web d'une seule page qui présente mon activité, dans un fichier index.html ». Et sur un vrai projet : « Explique-moi en trois phrases ce que contient ce dossier ».

Relis avant d'accepter

Quand Claude a modifié des fichiers, un petit compteur comme +12 -1 apparaît. Clique dessus pour voir, fichier par fichier, ce qui a changé. Tu peux commenter une ligne, Claude lit ton commentaire et corrige. Et tu peux le reprendre à tout moment : tape ta correction et Entrée, même pendant qu'il travaille.

Les autres modes, plus tard

Quand tu seras à l'aise, essaie le mode qui accepte tout seul les modifications de fichiers, ou le mode Auto, où un garde-fou vérifie chaque action en arrière-plan et bloque celles qui sont risquées. Le mode Plan, lui, fait proposer un plan à Claude avant qu'il touche à quoi que ce soit.

— Étape 03

Poser ton CLAUDE.md.

Le CLAUDE.md, c'est un petit fichier que Claude lit à chaque session. Tu y mets tes règles, ton style, ta stack technique. Ça évite de répéter "utilise Next.js" ou "réponds en français" à chaque fois.

Je te partage mon CLAUDE.md anonymisé comme point de départ. Tu l'ouvres, tu adaptes à ton style et ta stack, et voilà.

Télécharge mon CLAUDE.md

C'est un fichier .md de 100 lignes. Anonymisé, prêt à utiliser.

Transparence : ton email t'inscrit à ma newsletter AI Playbook (1 email/semaine sur l'IA en pratique). Désinscription en 1 clic.

01

Télécharge le fichier ci-dessus

Il va atterrir dans ton dossier Téléchargements.

02

Demande à Claude de le ranger au bon endroit

Le CLAUDE.md global vit dans un dossier caché, .claude, dans ton dossier personnel. Plutôt que de le chercher, ouvre une session dans l'onglet Code et demande : « Copie le fichier CLAUDE.md de mon dossier Téléchargements dans le dossier .claude de mon dossier personnel. Crée ce dossier s'il n'existe pas. » Il te demande la permission avant de copier, accepte.

03

Adapte-le avec Claude

Demande-lui ensuite : « Lis mon CLAUDE.md global et aide-moi à remplacer les sections Stack technique et Architecture Next.js par ma vraie stack ». Si tu ne sais pas quoi mettre, laisse. Tu ajusteras plus tard.

Astuce : 2 niveaux de CLAUDE.md

Tu peux avoir un ~/.claude/CLAUDE.md global (règles pour tous tes projets) + un CLAUDE.md à la racine d'un projet spécifique (règles locales). Les deux sont lus. Le second, Claude peut l'écrire pour toi : « Crée un CLAUDE.md avec les instructions pour ce projet ».

— Étape 04

Installer mes 26 skills.

Les skills (en clair : des « métiers » prêts à l'emploi pour Claude), c'est ce qui transforme Claude Code d'un simple assistant en spécialiste. Un skill = un dossier qui contient des instructions pour un métier précis : cold email, SEO, landing page, audit sécu, etc.

Quand tu demandes à Claude "écris-moi un cold email B2B", il charge automatiquement le skill cold-email et suit les règles définies dedans. Tu gagnes beaucoup de temps.

Télécharge mon pack de 26 skills

ZIP de 690 Ko. Contient tous mes skills custom + le CLAUDE.md + un README.

Transparence : ton email t'inscrit à ma newsletter AI Playbook. Désinscription 1 clic.

01

Dézippe le pack

Double-clique sur jeremy-claude-pack.zip dans ton dossier Téléchargements. Ça va créer un dossier jeremy-claude-pack.

02

Demande à Claude d'installer les skills

Tes skills personnels se rangent dans le dossier .claude/skills de ton dossier personnel. Dans une session de l'onglet Code, demande : « Copie tous les dossiers de Téléchargements/jeremy-claude-pack/skills dans le dossier .claude/skills de mon dossier personnel. Crée-le s'il n'existe pas. » Accepte la copie quand il te la propose.

03

Vérifie que ça marche

Ouvre une nouvelle session (le bouton + de la barre latérale, ou Cmd+N sur Mac, Ctrl+N sur Windows) et tape / dans la zone de message. La liste qui s'ouvre montre tes commandes et tes skills. Tu dois y voir cold-email, copywriting, graphify, etc. Tu peux aussi demander : « Liste-moi les skills que tu as chargés ».

Bravo, tu es prêt.

À partir de maintenant, Claude Code est opérationnel avec mon setup. Teste, casse, adapte. Le plus important, c'est de l'utiliser.

— Au quotidien

Comment je l'utilise
tous les jours.

Le matin — La veille

J'ouvre une session de l'onglet Code sur mon dossier de veille et je lui demande : "Utilise le skill deep-research pour me faire un résumé des 10 news IA les plus importantes cette semaine". Pendant qu'il travaille, je prends mon café. 10 minutes plus tard, j'ai un brief clair.

En journée — Construction

Quand j'ai besoin d'écrire une landing, un email, une page — je lance Claude Code. Il charge automatiquement le bon skill (copywriting, landing-page-generator, cold-email). Je lui donne le brief en 3 phrases, et il me produit un premier jet.

Le soir — Nettoyer le code

Avant de commit, je lui fais passer security-review sur le diff (la liste des changements faits depuis la dernière sauvegarde). En 30 secondes il me dit si j'ai laissé une clé API (la « carte d'accès » qui permet à ton code de parler à un service externe payant) traîner ou si une requête SQL est vulnérable.

Ce que je ne savais pas au début

Claude Code lance plusieurs sous-agents en parallèle (des « mini-Claude » qui bossent en même temps sur des bouts différents). Quand je lui demande "analyse ces 5 docs et synthétise", il lance 5 agents en parallèle, puis synthétise. 5× plus rapide qu'en séquentiel.

Les plugins officiels à connaître.

Anthropic expose plus de 140 plugins officiels sur son marketplace (le « magasin d'applications » officiel, sur claude.com/plugins). Un plugin, c'est un pack tout prêt de skills, commandes et agents qui s'installe en quelques clics depuis l'app. Tu n'as rien à configurer, rien à copier à la main. Installé pour toi, il est dispo dans tous tes projets.

Après plusieurs semaines de tests, voici les 6 que j'utilise. Tous ajoutent une vraie valeur pour un non-dev qui pilote des projets concrets.

Installe les 6 depuis l'app

Dans une session de l'onglet Code, clique sur le + à côté de la zone de message, puis sur Plugins, et ouvre la liste des plugins. Cherche chacun des six par son nom (superpowers, context7, claude-md-management, frontend-design, code-review, code-simplifier) et installe-le pour toi, pour qu'il serve dans tous tes projets. Ouvre ensuite une nouvelle session, et les nouvelles commandes apparaissent quand tu tapes / dans la zone de message. Dans la version terminal, ce sont six commandes, elles sont dans l'annexe.

Ce qu'ils apportent

01

superpowers — Méthodologie de dev complète

14 skills + 3 commandes slash (les raccourcis qui commencent par /) — /brainstorm, /write-plan, /execute-plan. Force Claude à spécifier avant de coder, à faire du TDD (Test-Driven Development · « écris d'abord le test, ensuite le code »), à passer en revue. Tape /brainstorm dans la zone de message avec une idée d'article ou de feature, tu verras la différence.

context7 — Docs à jour de n'importe quel framework (le « squelette » technique sur lequel un site/app est construit, ex : Next.js, React)

Skill qui se déclenche tout seul dès que tu travailles sur une page ou un composant. Génère des interfaces distinctes, évite les designs génériques d'IA. Utile quand tu refais une section du site ou tu crées une landing.

Agent qui simplifie le code récemment modifié. Utile quand Claude a écrit 400 lignes pour une fonction qui en méritait 100. Tu lui demandes "simplifie", il réduit sans casser le comportement.

Tu ne les lances pas chacun un par un. Ils se déclenchent tout seuls quand leur domaine est reconnu. Les commandes slash (/brainstorm, /revise-claude-md, /code-review) sont des outils ponctuels que tu appelles à la demande. Tout le reste est automatique.

— FAQ exhaustive

Tout ce qu'on me demande
sur Claude Code.

Vingt questions que je reçois par email ou en DM toutes les semaines. Réponses directes, en première personne, sans pose marketing.

C'est quoi Claude Code en une phrase ?

Claude Code est l'agent de code d'Anthropic, qui transforme l'IA Claude en assistant capable d'écrire, modifier, exécuter et déboguer du code directement sur ton ordinateur. Tu l'ouvres dans l'onglet Code de l'app Claude, sur Mac ou Windows. Au lieu de copier-coller du code depuis un chat, tu lui parles, et il agit dans tes fichiers.

Combien coûte Claude Code en 2026 ?

Claude Code est inclus dans l'abonnement Claude Pro à 20 $ par mois hors taxes (17 $ par mois en annuel) et dans Claude Max, à partir de 100 $ par mois. L'offre gratuite ne l'inclut pas. Dans la version terminal (voir l'annexe), tu peux aussi payer à l'usage avec une clé API Anthropic. Opus 5.5 y coûte 4 $ par million de tokens en entrée et 20 $ en sortie.

Pour un usage quotidien régulier, l'abonnement Pro reste l'option la plus rentable. Max devient intéressant quand tu touches les limites de Pro chaque semaine, ou si tu veux Fable 5.1, le modèle le plus puissant, inclus dans Max.

Faut-il être développeur pour utiliser Claude Code ?

Non. Je ne suis ni développeur ni codeur, et je l'utilise tous les jours pour écrire des newsletters, monter des landing pages, automatiser des tâches. Claude Code lit ton intention en français et fait le travail technique à ta place.

Tu as juste besoin d'installer l'app Claude et de décrire ce que tu veux, comme dans un message. Aucune commande à taper, tout se passe dans l'onglet Code.

Claude Code vs Cursor : lequel choisir ?

Cursor est un éditeur de code (un fork de VS Code) avec autocomplete IA et chat intégré. Claude Code est un agent autonome qui exécute des tâches sur ton ordinateur, depuis l'onglet Code de l'app Claude. Si tu veux remplacer VS Code et garder le contrôle ligne par ligne, prends Cursor. Si tu veux déléguer des tâches entières à un agent qui lit, écrit et teste à ta place, prends Claude Code.

Mon usage : Claude Code en principal pour les tâches lourdes, Cursor en complément quand je veux voir le diff en direct. Les deux coûtent 20 $/mois, tu peux tester les deux.

Claude Code vs Codex (OpenAI) : quelles différences ?

Codex tourne sur les modèles GPT d'OpenAI (aujourd'hui GPT-6.1 Sol). Claude Code tourne sur les modèles Claude d'Anthropic (Opus 5.5, Sonnet 5.5, Fable 5.1). D'après mon expérience, Claude est meilleur pour comprendre un codebase existant et raisonner sur du contexte long. Codex est souvent plus rapide sur des tâches courtes et créatives.

Le choix dépend surtout de l'écosystème dans lequel tu vis déjà. Si tu as ChatGPT Plus (20 $/mois) ou une offre au-dessus, Codex est inclus et tu n'as rien à ajouter. Si tu veux la qualité de raisonnement maximale, Claude Code reste mon choix.

Comment installer Claude Code ?

Télécharge l'app Claude sur claude.com/download, installe-la sur ton Mac ou ton PC Windows et connecte-toi avec un abonnement payant (Pro ou au-dessus). Clique sur l'onglet Code, choisis un dossier de ton ordinateur, et c'est prêt. Aucune commande à taper.

Le pas à pas est plus haut sur cette page, avec le dépannage et la configuration du CLAUDE.md. Compte 20 minutes la première fois. Si tu préfères la version terminal, elle est dans l'annexe, tout en bas.

Sur quels systèmes d'exploitation Claude Code fonctionne-t-il ?

L'app Claude et son onglet Code tournent sur macOS (Intel et Apple Silicon) et sur Windows, et une version Linux est en bêta. C'est la voie la plus simple, et celle de ce guide.

La version terminal tourne aussi sur macOS, Linux et Windows, directement ou via WSL. Elle est décrite dans l'annexe en bas de page.

Comment Claude Code gère-t-il mes secrets et fichiers .env ?

Claude Code lit le contenu des fichiers que tu lui demandes de lire. Si tu lui demandes d'ouvrir un fichier .env, il le verra.

Bonnes pratiques : ajoute .env à ton .gitignore, n'ouvre jamais explicitement le fichier dans tes prompts, et utilise le skill security-review avant chaque commit pour qu'il vérifie qu'aucune clé n'a été laissée en clair dans le code. Tu peux aussi configurer un hook qui interdit toute écriture dans les fichiers .env.

Claude Code peut-il accéder à Internet ?

Oui, via plusieurs outils intégrés. WebFetch lit une page web précise, WebSearch fait une recherche, et le plugin context7 fetch la documentation officielle des frameworks à jour.

D'après mon expérience, c'est indispensable dès que tu travailles sur une stack qui évolue vite (Next.js, Tailwind, Stripe). Sans accès à Internet, Claude risque de te répondre sur la version d'il y a 18 mois.

Claude Code peut-il travailler sur plusieurs fichiers en parallèle ?

Oui. C'est même un de ses superpouvoirs. Claude Code lance des sous-agents en parallèle quand la tâche le permet. Tu lui demandes d'analyser cinq documents, il lance cinq agents simultanément, puis synthétise. Tu lui demandes de modifier plusieurs fichiers liés, il les ouvre en parallèle.

Pour aller plus loin, lis mon article Les loops Claude Code, expliqués qui détaille la mécanique d'exécution.

Quel est le contexte token de Claude Code ?

Les quatre modèles Claude de novembre 2026 (Opus 5.5, Sonnet 5.5, Haiku 5.5 et Fable 5.1) ont tous 1 million de tokens de contexte.

Concrètement, ça veut dire que Claude Code peut lire un codebase entier de plusieurs dizaines de milliers de lignes sans perdre le fil. À titre de comparaison : ce site fait environ 50 000 tokens si on prend tous les fichiers HTML, donc il rentre en entier dans le contexte d'une seule session.

Comment utiliser MCP avec Claude Code ?

MCP (Model Context Protocol) est un standard ouvert qui permet à Claude Code de se connecter à des services externes : bases de données, Sanity, Stripe, Telegram, n'importe quel CRM.

Dans l'app Claude, tu cliques sur le + à côté de la zone de message et tu ouvres les connecteurs pour brancher le service en quelques clics. Ceux qui ne sont pas dans la liste s'ajoutent dans un fichier de réglages (par exemple .mcp.json à la racine du projet), que Claude peut écrire pour toi. Claude Code peut ensuite l'appeler comme n'importe quel outil natif. Beaucoup de fournisseurs proposent maintenant un MCP server officiel.

Skills vs Slash commands : quelle différence ?

Un skill est un dossier d'instructions qui se déclenche automatiquement quand Claude reconnaît le domaine de ta demande. Exemple : le skill cold-email se charge tout seul quand tu écris « rédige un cold email B2B ».

Un slash command est un raccourci manuel que tu tapes dans la zone de message (exemple : /brainstorm) pour lancer un workflow précis. Les skills sont automatiques, les slash commands sont volontaires. Les deux peuvent coexister : un slash command peut appeler un skill.

Comment versionner mes commandes Claude Code dans Git ?

Ton dossier ~/.claude/ contient ton CLAUDE.md global, tes skills, tes hooks et tes settings. Tu peux le suivre dans un dépôt Git privé pour partager ton setup entre plusieurs machines.

Pour un projet, le CLAUDE.md local et le dossier .claude/ vivent à la racine et sont commités avec le code. C'est ce qui permet à un nouveau collaborateur (humain ou IA) de récupérer le contexte projet sans avoir à reposer toutes les questions.

Les hooks Claude Code : à quoi ça sert ?

Les hooks sont des scripts qui se déclenchent automatiquement sur des événements précis : avant une réponse, après un tool call, à l'arrêt d'une session.

Concrètement, tu peux brancher une notification Telegram à la fin d'une tâche longue (pour que ton téléphone sonne quand le build est fini), interdire à Claude de toucher à certains fichiers sensibles, ou déclencher un audit sécurité avant chaque commit. C'est ce qui sépare un Claude Code « out of the box » d'un Claude Code adapté à ton workflow.

Claude Code en mode Plan Mode : quand l'utiliser ?

Le Plan Mode force Claude à présenter son plan d'action avant d'agir. Dans l'app, tu choisis Plan dans le sélecteur de mode, sous la zone de message.

C'est utile dès que la tâche dépasse trois fichiers ou touche à de la base de données. Tu valides le plan ou tu le corriges avant qu'un seul fichier ne soit touché. Mon réflexe : Plan Mode obligatoire dès qu'il y a un risque de casser quelque chose, ou que la tâche peut prendre une mauvaise direction si Claude se trompe dans son interprétation.

Peut-on lancer Claude Code dans GitHub Actions ou en CI ?

Oui. Anthropic propose une intégration GitHub Actions officielle. Tu déclenches Claude Code sur un événement (pull request, push, issue), il fait sa tâche en mode non-interactif et commit le résultat.

Pratique pour automatiser des revues de code, des audits, de la documentation, ou de la génération de release notes. Demande une clé API Anthropic stockée en secret GitHub. Pour creuser, va voir la fiche lexique GitHub Actions.

Vie privée des données : Anthropic garde-t-il mon code ?

Par défaut, Anthropic ne retient pas tes données pour entraîner ses modèles si tu es sur un compte Pro ou API. Les conversations Claude Code peuvent être stockées 30 jours pour la modération abuse, puis effacées.

Pour un usage en entreprise avec données sensibles, l'option Zero Data Retention existe sur les comptes Enterprise. Si tu travailles sur du code client confidentiel, c'est l'option à demander à ton commercial Anthropic.

Quelles sont les limites connues de Claude Code en 2026 ?

Trois limites que je rencontre régulièrement :

1. Il invente parfois des fonctions d'une librairie qui n'existent pas (utilise le plugin context7 pour lui donner la doc à jour, ça règle 80 % du problème).

2. Il a tendance à sur-écrire le code en ajoutant trop de commentaires (le skill code-simplifier corrige).

3. Il peut perdre le fil sur des sessions très longues (au-delà de 500 000 tokens, j'ouvre une nouvelle session). Plus une limite humaine : Claude Code ne remplace pas un dev senior pour des décisions d'architecture critiques.

Quel modèle Claude utiliser : Opus, Sonnet ou Fable ?

En novembre 2026, Opus 5.5 est le modèle qu'Anthropic conseille pour commencer, très fort en code et en agents, et inclus dans Pro. Sonnet 5.5 est le meilleur compromis entre vitesse et intelligence. Haiku 5.5 est le plus rapide et le moins cher, pour trier ou extraire beaucoup de textes. Fable 5.1 est le plus puissant, à garder pour les cas durs. Il est inclus dans Max (jusqu'à la moitié de la limite de la semaine) et se paie en crédits d'usage sur Pro.

Anthropic conseille de partir d'Opus 5.5 et de passer à Fable 5.1 seulement si ça ne suffit pas. Tu changes de modèle quand tu veux, même en cours de session, avec le sélecteur de modèle au bout de la ligne sous la zone de message. Pour comparer en détail, va voir la page modèles IA.

Même moteur, mêmes réglages : ton CLAUDE.md, tes skills, tes hooks et tes serveurs MCP servent aux deux, et tu peux utiliser les deux sur le même projet.

Elle sert surtout pour ce que l'app ne fait pas, comme le mode script (claude -p), les équipes d'agents ou le paiement à l'usage avec une clé API Anthropic.

Pas besoin pour démarrer

Si tu débutes, tu peux t'arrêter avant cette annexe, tout le guide marche dans l'app. Ce qui suit, c'est pour ceux qui aiment voir sous le capot.

Le terminal que j'utilise, Ghostty (optionnel)

Ghostty, c'est le terminal que j'utilise sur Mac. C'est gratuit, rapide, beau, et il supporte les emojis. Tu n'es pas obligé de l'installer, le Terminal de macOS (déjà là, cherche « Terminal » dans Spotlight) fait parfaitement le boulot.

01

Télécharge Ghostty

Va sur ghostty.org et clique "Download". C'est gratuit, pas d'email demandé.

02

Installe l'app

Double-clique sur le fichier .dmg téléchargé, glisse Ghostty dans ton dossier Applications. Ouvre-le. macOS va te demander si tu fais confiance, clique "Oui".

03

Vérifie que ça marche

Ghostty ouvert, tape cette commande puis Entrée :

echo "Salut Ghostty"

Si tu vois Salut Ghostty s'afficher, tu es prêt pour la suite.

Installer Claude Code en ligne de commande

Ouvre ton terminal (Ghostty ou Terminal) et colle la commande officielle. Sur Mac ou Linux :

curl -fsSL https://claude.ai/install.sh | bash

Sur Windows, dans PowerShell :

irm https://claude.ai/install.ps1 | iex

Pourquoi cette commande ?

Elle télécharge le script officiel d'Anthropic et l'exécute. Il installe Claude Code dans ton système. Tu peux lire le script avant de l'exécuter si ça te rassure, c'est le lien dans la commande.

01

Lance la commande

Colle-la dans ton terminal, appuie sur Entrée, attends qu'elle finisse. Elle n'affiche pas de progression pendant le téléchargement, c'est normal.

02

Relance ton terminal

Ferme complètement le terminal (Cmd+Q sur Mac) et rouvre-le, pour que la nouvelle commande claude soit prise en compte. Puis vérifie :

claude --version

Tu dois voir un numéro de version, par exemple 2.1.211 (Claude Code).

03

Connecte ton compte Claude

Tape :

claude

La première fois, il ouvre ton navigateur pour te connecter. Il faut le même abonnement payant que pour l'app, ou un compte API Anthropic. C'est 30 secondes.

04

Teste

Crée un dossier vide sur ton bureau, ouvre-le dans le terminal et lance Claude :

mkdir ~/Desktop/test-claude
cd ~/Desktop/test-claude
claude

Demande-lui par exemple : "Crée-moi un fichier hello.txt avec 'Hello world' dedans". Tu verras qu'il le crée tout seul.

Les mêmes réglages, en commandes

Ce que l'app fait pour toi plus haut, voici la version tapée.

Poser le CLAUDE.md global

mkdir -p ~/.claude
cp ~/Downloads/CLAUDE.md ~/.claude/CLAUDE.md
open ~/.claude/CLAUDE.md

Installer les 26 skills du pack

mkdir -p ~/.claude/skills
cp -R ~/Downloads/jeremy-claude-pack/skills/* ~/.claude/skills/

Installer les 6 plugins

claude plugin install superpowers
claude plugin install context7
claude plugin install claude-md-management
claude plugin install frontend-design
claude plugin install code-review
claude plugin install code-simplifier

Puis relance Claude Code. Dans une session, la commande /plugin ouvre aussi le gestionnaire de plugins.

Modèle, Plan Mode et autopilot

/model change de modèle en cours de session. Shift+Tab fait défiler les modes, dont le Plan Mode. Et claude --dangerously-skip-permissions lance une session sans aucune demande d'autorisation, à réserver à des worktrees Git séparés. C'est l'équivalent du mode sans autorisation de l'app.

Dépannage de la version terminal

La commande claude n'est pas reconnue

Ouvre une nouvelle fenêtre de terminal. Si ça ne change rien sur Mac, ajoute le dossier de Claude Code à ton PATH :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Pour un bilan complet de ton installation, lance claude doctor.

Claude ne charge pas mes skills

ls ~/.claude/skills/

Tu dois voir la liste des skills. Si le dossier est vide, refais la copie plus haut.

Claude ne lit pas mon CLAUDE.md

cat ~/.claude/CLAUDE.md

S'il affiche un contenu, c'est bon. Claude le lit automatiquement à chaque session.

Passer d'une version à l'autre

Une session commencée dans le terminal peut continuer dans l'app. Tape /desktop dans la session, elle s'ouvre dans l'onglet Code (sur Mac et Windows, avec un abonnement Claude). Dans l'autre sens, ferme la session du terminal, puis tape /resume dans la zone de message de l'app.

Retour à l'app

Si tu veux juste avancer, tout le reste du guide marche sans une seule ligne de commande. Retour à l'étape 01.
