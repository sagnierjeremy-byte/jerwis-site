Suppression de tes données

Comment faire effacer tout ce que jerwis.fr a collecté sur toi, y compris via Meta Pixel. 1 email = on s'occupe du reste.

← retour à l'accueil

01 Ce que cette page concerne

Cette page documente la procédure de suppression des données collectées par Jerwis Conseil via les services Meta (Facebook, Instagram), notamment :

  • Les événements générés par le Meta Pixel installé sur jerwis.fr (page view, achat, etc.)
  • Les événements server-side envoyés via la Conversions API (Purchase event après paiement Stripe)
  • Les données de matching utilisées pour mesurer l'efficacité des pubs Facebook/Instagram (email haché SHA-256, cookies _fbp/_fbc)

Pour les autres données (newsletter, factures, etc.), consulte la Politique de confidentialité qui couvre l'ensemble des traitements.

02 Procédure de suppression

La procédure est volontairement simple. Pas de formulaire, pas de compte à créer, pas de validation par captcha :

Envoie un email à :

jeremy.sagnier@jerwis.fr

Objet : Suppression RGPD - données Meta

Précise dans le corps du message :

  1. L'adresse email que tu as utilisée sur le site (pour qu'on retrouve les événements de matching)
  2. Optionnel : ton identifiant Facebook ou Instagram si tu veux la suppression croisée
  3. Si tu souhaites uniquement supprimer les données Meta ou tout supprimer (newsletter, factures anonymisées, etc.)

03 Ce qui sera fait

Sous 7 jours ouvrés max à compter de la réception de ta demande :

  1. Suppression des événements Meta Pixel et Conversions API associés à ton email haché, via l'API Meta Custom Audiences Removal et l'API de suppression Conversions API.
  2. Suppression des cookies _fbp et _fbc côté navigateur (ils s'effaceront automatiquement à expiration au max 90j si tu ne reviens pas sur le site).
  3. Confirmation par email à l'adresse depuis laquelle tu as envoyé la demande, avec capture d'écran de la réponse Meta.

Limites : les événements Meta sont également stockés du côté de Meta Platforms Inc. selon leurs propres règles. La suppression côté Jerwis Conseil n'efface pas automatiquement les données chez Meta. Pour une suppression complète chez Meta, utilise aussi : Centre de confidentialité Facebook.

04 Retirer ton consentement sans demande spécifique

Si tu veux juste arrêter le tracking sans faire de demande RGPD :

  • Refuse les cookies via le banner en bas de page (lien "Gérer mes cookies")
  • Bloque les cookies tiers dans ton navigateur (Safari et Firefox le font par défaut, Chrome propose un toggle dans les Paramètres)
  • Active une extension type uBlock Origin ou Privacy Badger
  • Sur ton compte Meta : Préférences publicitaires → désactive "Activités sur d'autres sites web utilisant Meta"

05 Recours

Si tu juges que la suppression n'a pas été effectuée correctement ou dans les délais, tu peux porter réclamation auprès de la CNIL, autorité de contrôle française des données personnelles.

Pour une réclamation directement contre Meta, contacte le Data Protection Commission irlandais (autorité chef de file de Meta pour l'UE).
