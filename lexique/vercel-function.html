Vercel Function

Une Vercel Function, c'est un bout de code serveur qui s'exécute à la demande, sans que tu aies à gérer ni payer un serveur en permanence. Pour la plupart des cas simples (une API, un webhook, un appel à une IA), elle remplace tout un backend à zéro effort.

— Définition

Vercel Function, en clair

En clair : tu écris juste une petite fonction, par exemple dans /api/subscribe.js pour envoyer un email, et Vercel se charge de la faire tourner quand on l'appelle.

Vois ça comme une fonction à la demande, pas comme un serveur permanent qui tourne 24h/24 : à éviter pour du code long, à cause des limites de temps d'exécution selon le plan.

Exemple concret

Mon site a un formulaire qui envoie un email. Au lieu de gérer un serveur Node, j'écris une fonction dans /api/subscribe.js. Vercel s'occupe du reste.

Pourquoi ça compte

Pour 80% des cas (API simple, webhook, intégration IA), les Vercel Functions remplacent un serveur backend à zéro effort.

Tu la croises dans les dossiers /api, les formulaires newsletter, les webhooks, les appels IA et les logs Vercel.

À ne pas confondre

Edge Function Supabase : Une Edge Function Supabase lance du code serveur pour connecter une app à des API ou traiter une action sensible.

Webhook : Un webhook est une URL appelée automatiquement quand un événement arrive.

Erreurs fréquentes

  • Y mettre du code long (limite de timeout selon le plan).
  • Oublier de fixer les variables d'environnement côté Vercel.
  • Confondre Vercel Functions (serverless) et Edge Functions (différent runtime).
