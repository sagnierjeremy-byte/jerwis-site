Glossaire IA · P1

Tool use / Function calling

Le tool use (ou function calling) permet à un modèle d'IA d'appeler un outil externe au lieu de seulement répondre avec du texte. Le modèle comprend qu'il doit, par exemple, chercher un prix sur le web, lance l'outil, récupère le résultat et rédige sa réponse avec. C'est ce qui transforme un chatbot en agent capable d'agir.

— Définition

Tool use / Function calling, en clair

En clair : au lieu de juste parler, l'IA peut désormais déclencher des actions, comme envoyer un email, lire un fichier ou interroger une API.

Vois ça comme la bascule majeure vers les agents : sans outils, l'IA reste enfermée dans la conversation ; avec outils, elle agit dans un système réel.

Exemple concret

Le modèle comprend qu'il doit vérifier un prix, appelle l'outil de recherche, puis rédige la réponse avec le résultat.

Pourquoi ça compte

Sans outils, un agent reste enfermé dans la conversation. Avec outils, il peut agir dans un système réel.

Tu le vois dans les agents qui envoient un email, lisent un fichier, cherchent sur le web ou appellent une API.

À ne pas confondre

MCP : MCP, pour Model Context Protocol, est un standard qui permet à une IA de se connecter proprement à des outils et des données.

Workflow agentique : Un workflow agentique est une suite d'étapes où l'IA planifie, utilise des outils, vérifie et continue jusqu'au résultat.

Erreurs fréquentes

  • Donner trop d'outils sans règles.
  • Laisser l'agent appeler une action sensible sans validation.
  • Ne pas journaliser les appels d'outils.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Le modèle comprend qu'il doit vérifier un prix, appelle l'outil de recherche, puis rédige la réponse avec le résultat.
  • Je garde en tête le piège principal : Donner trop d'outils sans règles.

Questions rapides

C'est quoi Tool use / Function calling en IA ?

Le tool use (ou function calling) permet à un modèle d'IA d'appeler un outil externe (recherche web, lecture de fichier, envoi d'email, appel d'API) au lieu de seulement produire du texte. C'est le mécanisme de base qui transforme un modèle en agent.

Où vais-je croiser Tool use / Function calling ?

Tu le vois dans les agents qui envoient un email, lisent un fichier, cherchent sur le web ou appellent une API.

Quel mot lire après Tool use / Function calling ?
