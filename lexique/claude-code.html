Claude Code

Claude Code, c'est l'agent de Claude qui travaille directement dans ton projet : il lit tes fichiers, propose des modifications et lance des commandes, mais toujours avec ton accord. Pense à un copilote qui agit sur ton code, pas à un simple chat. C'est l'outil qui m'a permis de livrer des projets entiers sans savoir coder.

— Définition

Claude Code, en clair

En clair : tu lances Claude dans un dossier, tu décris ce que tu veux, il te montre les changements, et tu valides ou tu refuses avant qu'il applique quoi que ce soit.

Ne le vois pas comme ChatGPT qui te recrache du texte à copier : Claude Code touche vraiment à ton projet, donc tu gardes la main et tu relis ce qu'il propose.

Exemple concret

Je lance claude dans un dossier, je décris la modif, il propose un diff, je valide ou je refuse, il applique.

Pourquoi ça compte

C'est l'outil qui m'a permis de livrer des projets entiers sans savoir coder. Le mot revient dans toutes les discussions agents.

Tu le croises dans les tutos terminal, les agents, GitHub Actions, les reviews et les automatisations de projet.

À ne pas confondre

CLAUDE.md : CLAUDE.md est le fichier où tu notes les règles du projet pour que Claude ne reparte pas de zéro.

Slash command : Une slash command est une commande courte qui lance une instruction préparée dans un outil IA.

Erreurs fréquentes

  • Croire que c'est un chat à la ChatGPT alors que c'est un agent qui modifie ton projet.
  • Lui donner accès au système entier sans relire les commandes proposées.
  • Oublier d'écrire un CLAUDE.md et repartir à chaque session de zéro.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Je lance claude dans un dossier, je décris la modif, il propose un diff, je valide ou je refuse, il applique.
  • Je garde en tête le piège principal : Croire que c'est un chat à la ChatGPT alors que c'est un agent qui modifie ton projet.
