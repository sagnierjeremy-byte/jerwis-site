Sandbox

Une sandbox, c'est un espace isolé où une IA ou un agent peut agir sans risquer d'abîmer le reste de ta machine. Si l'agent fait une bêtise, les dégâts restent enfermés dedans : le pire scénario, c'est de remettre l'espace à zéro. Tu la croises dès qu'un agent exécute du code à ta place.

— Définition

Sandbox, en clair

En clair : c'est une pièce fermée où l'agent peut faire ce qu'il veut sans toucher à tes vrais fichiers. Tout casse à l'intérieur, rien dehors.

Ne crois pas pour autant qu'une sandbox te protège de tout : elle limite les dégâts, mais ce n'est pas une sécurité absolue, surtout si tu lui ouvres internet sans raison.

Exemple concret

Codex tourne dans un container isolé. Si l'agent fait n'importe quoi, ton ordi reste intact, le container saute.

Pourquoi ça compte

Sans sandbox, un agent qui se trompe peut tout casser sur ta machine. Avec, le pire scénario est un reset.

Tu la vois dans Codex cloud, les agents qui exécutent du code, les tests et les environnements contrôlés.

À ne pas confondre

Permission d'outil : Une permission d'outil décide ce qu'un agent a le droit de lire, écrire ou lancer.

Moindre privilège : Le moindre privilège consiste à donner à l'agent seulement les droits nécessaires.

Erreurs fréquentes

  • Donner accès au système hôte depuis la sandbox.
  • Oublier de couper internet dans la sandbox quand pas nécessaire.
  • Croire qu'une sandbox équivaut à une sécurité totale.

Questions rapides

C'est quoi Sandbox en IA ?

Une sandbox est un espace isolé où une IA ou un agent exécute du code ou des actions sans pouvoir abîmer le reste de la machine. En cas d'erreur, les dégâts restent confinés à cet espace.
