Sous-agent

Un sous-agent est un assistant IA spécialisé à qui un agent principal confie une partie précise du travail. L'agent principal pilote, puis délègue : un sous-agent pour la recherche, un autre pour la relecture. Chacun garde un contexte propre et une expertise nette, ce qui évite de tout mélanger.

— Définition

Sous-agent, en clair

En clair : c'est un spécialiste qu'on appelle au bon moment pour une tâche donnée, pas un clone qui fait tout.

Vois ça comme une équipe : le chef de projet (l'agent principal) répartit les missions à des collègues experts (les sous-agents) au lieu de tout faire seul.

Exemple concret

Mon agent principal écrit l'article. Pour la recherche, il délègue à un sous-agent Explore. Pour la review, à un sous-agent Code Review.

Pourquoi ça compte

Un sous-agent garde un contexte propre, une expertise nette. Tu évites que ton agent principal mélange tout.

Tu le croises dans Codex, Claude Code, les workflows de recherche, les reviews et les veilles multi-agents.

À ne pas confondre

Workflow agentique : Un workflow agentique est une suite d'étapes où l'IA planifie, utilise des outils, vérifie et continue jusqu'au résultat.

Multi-agent : Un système multi-agent fait travailler plusieurs agents spécialisés sur une même mission.

Erreurs fréquentes

  • Créer un sous-agent pour chaque petit truc et perdre l'avantage.
  • Oublier de définir clairement la mission du sous-agent.
  • Ne pas lui passer les bonnes infos en input.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Mon agent principal écrit l'article. Pour la recherche, il délègue à un sous-agent Explore. Pour la review, à un sous-agent Code Review.
  • Je garde en tête le piège principal : Créer un sous-agent pour chaque petit truc et perdre l'avantage.
