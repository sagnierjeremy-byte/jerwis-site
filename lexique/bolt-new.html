Bolt.new

Bolt.new, c'est l'outil de StackBlitz qui te fabrique une vraie application web complète à partir d'une simple description. Tu écris 'fais-moi une app de to-do list avec login', il génère le code et te le montre en direct dans le navigateur. Idéal pour prototyper une idée sans coder.

— Ce que c'est

Bolt.new, en clair

En clair : tu décris ton idée en français, Bolt code l'app, l'affiche en live à droite de l'écran, et tu l'ajustes en continuant à discuter.

Ce qui change vs un Cursor ou un Windsurf : tu n'as rien à installer, tout tourne dans le navigateur. Tu décris ton idée, Bolt code, tu vois le résultat en direct dans la moitié droite de l'écran. Tu modifies par chat, le code se met à jour.

Derrière, ils utilisent Claude Sonnet 4.6 par défaut (ils sont partenaires d'Anthropic) et te permettent de déployer en un clic sur Netlify ou Vercel.

À quoi ça me sert

  • Prototyper une idée business : "fais-moi un calculateur de TVA européenne avec formulaire et résultat" — Bolt te sort une app en 2 minutes. Suffisant pour montrer à un partenaire.
  • Tester une landing page : décrire une page, voir le rendu, itérer 5 fois en 30 minutes. Plus rapide que de briefer un designer.
  • Apprendre par l'exemple : tu décris, Bolt code, tu lis le code généré pour comprendre comment c'est fait. Pédagogie efficace.
  • Outils internes simples : un mini-dashboard pour suivre des trucs, un formulaire interne — Bolt suffit, pas besoin de dev.
  • Maquette pour ton développeur : tu donnes le prototype Bolt à un vrai dev qui finalise pour la production.

Comment ça se compare

vs v0 by Vercel : v0 est plus orienté composants design (React + Tailwind). Bolt génère une app complète avec back-end. Choisir v0 pour du design pur, Bolt pour une app fonctionnelle.

vs Lovable : Lovable est un concurrent direct, sortie similaire (fin 2024). Lovable est plus orienté SaaS, Bolt plus polyvalent. Match nul, à tester selon ton cas.

vs Cursor / Windsurf : Cursor/Windsurf sont des IDE pour devs. Bolt est un outil sans-code pour non-devs. Si tu sais coder, Cursor/Windsurf sont plus puissants. Si tu ne codes pas, Bolt est plus simple.

Combien ça coûte

Prix au 25 mai 2026 (source : bolt.new/pricing) :

  • Free : gratuit — 200k tokens/jour, suffit pour tester
  • Pro : 20 $/mois — 10M tokens/mois, projets privés, déploiement Vercel
  • Teams : 50 $/mois par utilisateur — gestion d'équipe, GitHub sync, support

Attention : Bolt facture en tokens. Une app complexe peut consommer plusieurs centaines de milliers de tokens. Bien surveiller la consommation au début.

Mon avis

J'ai testé Bolt pour bricoler des mini-outils internes (calculateurs, formulaires de qualification). Pour ça, c'est bluffant. Une app fonctionnelle en 10 minutes sans toucher au code.

Ce que j'aime : la magie de voir une app prendre forme en direct, le déploiement en un clic, l'export GitHub pour passer la main à un vrai dev ensuite.

Ce qui m'agace : ça consomme vite des tokens dès qu'on itère, et le résultat reste fragile. Tant qu'on prototype, super. Pour partir en production avec des vrais utilisateurs, il faut un dev qui reprend derrière. Pas un remplaçant, un accélérateur.

Questions rapides

Bolt.new pour un non-dev ?

Bolt.new est l'outil de StackBlitz qui crée une application web complète à partir d'une description en langage naturel, sans coder : le code est généré et affiché en direct dans le navigateur, puis exportable sur GitHub.

Quel modèle IA Bolt utilise ?

Claude Sonnet 4.6 par défaut, avec accès à d'autres modèles selon le plan.

Mon app Bolt est-elle vraiment à moi ?

Oui, tu exportes le code sur GitHub. Pas de vendor lock-in technique.
