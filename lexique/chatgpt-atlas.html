Agent navigateur · OpenAI · 2026

ChatGPT Atlas / Operator

ChatGPT Atlas (dérivé du projet Operator) est le navigateur web d'OpenAI avec un agent IA intégré : tu lui dis ce que tu veux ("réserve cette table", "achète ce produit"), il prend la main, ouvre les sites, clique et remplit à ta place. Réservé aux abonnés ChatGPT Pro et Business.

— Ce que c'est

ChatGPT Atlas / Operator, en clair

En clair : c'est Chrome version OpenAI, sauf qu'une IA est aux commandes du navigateur et fait les tâches web à ta place pendant que tu fais autre chose.

Concrètement, je lui dis : "trouve les 3 vols les moins chers Paris-Marseille pour vendredi, mets-les dans un tableau, et réserve le moins cher si moins de 80 €". Atlas ouvre les sites, compare, et réserve si la condition est remplie. Il me demande validation pour le paiement.

Comme Perplexity Comet, mais avec la techno OpenAI derrière (modèle "Computer Use" qui voit et interagit avec n'importe quelle interface web).

À quoi ça me sert

Les cas où je sors Atlas / Operator :

  • Achats e-commerce automatisés : remplir le panier sur 3 sites, comparer, finir la commande.
  • Réservations : restaurant, vol, hôtel, médecin. Atlas navigue le site, remplit les champs, je valide.
  • Candidatures en série : si tu cherches un freelance ou un emploi, il peut remplir 20 formulaires similaires.
  • Suivi de prix : "passe sur ce site tous les jours, alerte-moi si le prix baisse sous 100 €".
  • Veille concurrentielle profonde : tour de 30 sites avec extraction d'infos structurées dans un tableau.

Comment ça se compare

vs Perplexity Comet : Comet est bien plus accessible (20 $/mois vs 200 $/mois). Atlas est plus performant sur les actions complexes (paiements, multi-étapes).

vs Genspark : Genspark mise sur les livrables (slides, docs, calls). Atlas mise sur l'action web pure.

vs Manus / agents Chinois : Manus a montré des démos impressionnantes mais reste en accès limité. Atlas est productisé et stable.

Combien ça coûte

Prix en mai 2026 (source : openai.com/chatgpt/pricing) :

  • ChatGPT Plus : 20 $/mois : accès limité à Atlas / Operator
  • ChatGPT Pro : 200 $/mois : accès complet à Atlas, usage intensif, modèles premium
  • Business : à partir de 25 $/utilisateur/mois : pour les équipes

Atlas est distribué comme navigateur autonome (Mac, Windows). Le téléchargement est gratuit, mais sans abonnement Pro, l'agent est très limité.

Mon avis

C'est le plus avancé techniquement aujourd'hui. Quand Atlas fonctionne, il fait des trucs que les autres ne savent pas faire (compléter un achat de A à Z, gérer une réservation à étapes).

Le bémol : 200 $/mois, c'est cher pour un usage occasionnel. Et l'agent est encore lent (souvent 2-3 minutes pour une tâche). Tu peux faire la même chose plus vite à la main pour 10 minutes de boulot.

Je l'utilise pour les tâches répétitives où le gain de temps justifie l'attente. Pour le reste, Comet à 20 $/mois fait largement le job.

Questions rapides

Atlas est dispo en France ?

ChatGPT Atlas est le navigateur web d'OpenAI, issu du projet Operator, doté d'un agent IA qui exécute des tâches web complètes (réserver, acheter, remplir des formulaires) à la place de l'utilisateur. Accès via ChatGPT Pro et Business.

L'agent peut payer sans demander ?

Non, validation manuelle requise par défaut. Tu peux régler les seuils dans les options.

Mes données passent par OpenAI ?

Oui pour les sessions agent, voir la politique de confidentialité OpenAI. Option "Temporary Chat" disponible.
