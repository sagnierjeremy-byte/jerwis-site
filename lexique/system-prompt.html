System prompt

Le system prompt, c'est l'instruction de niveau supérieur qui cadre le comportement d'une IA pendant toute la conversation : sa langue, son ton, ses limites. Il donne une cohérence aux réponses et freine certains comportements risqués, avant même que tu poses ta question.

— Définition

System prompt, en clair

En clair : c'est la consigne de fond qui reste valable tout du long, par exemple 'réponds en français, cite tes sources, demande validation avant toute action sensible'.

Vois-le comme un cadre, pas comme une formule magique : il oriente le modèle mais ne bloque pas toutes les attaques. Ne le confonds pas avec le prompt engineering, qui est l'art de bien formuler chaque demande au coup par coup.

Exemple concret

Un system prompt peut dire : réponds en français, cite tes sources, demande validation avant toute action sensible.

Pourquoi ça compte

Il donne une cohérence aux réponses et limite certains comportements risqués.

Tu le croises dans les API IA, les instructions personnalisées, AGENTS.md, CLAUDE.md ou les builders d'agents.

À ne pas confondre

Prompt engineering : Le prompt engineering consiste à formuler une demande avec assez de contexte, d'exemples et de contraintes pour obtenir une réponse utile.

Guardrail : Un guardrail est une règle de sécurité qui limite ce qu'une IA ou un agent peut faire.

Erreurs fréquentes

  • Le remplir de règles contradictoires.
  • Croire qu'il bloque toutes les attaques.
  • Le modifier à chaque message alors qu'il doit rester stable.

Mini-checklist
