Clé API

Une clé API, c'est un mot de passe technique qui autorise un outil à appeler un service d'IA en ton nom, sans lui donner accès à tout ton compte. Tu t'en sers dès que tu branches une IA dans une automatisation : c'est elle qui ouvre la porte, et qui fait tourner la facture.

— Définition

Clé API, en clair

En clair : c'est un badge d'accès. Tu le donnes à un outil, et il peut utiliser ton service d'IA à ta place, mais seulement dans la limite de ce badge.

Ne la confonds pas avec ton mot de passe de compte : la clé API sert juste aux machines qui se parlent entre elles. Et traite-la comme un secret, une clé qui fuite, ce sont des dépenses à ta charge.

Exemple concret

Tu branches Claude à n8n : n8n ne connaît pas ton compte complet, il utilise seulement la clé API que tu lui donnes.

Pourquoi ça compte

Dès que l'IA sort du chat et entre dans une automatisation, la clé API devient le point d'entrée principal.

Tu la vois dans les consoles Anthropic, OpenAI, Resend, Supabase, Vercel ou dans les champs de connexion d'un outil no-code.

À ne pas confondre

Fichier .env : Un fichier .env range les clés et réglages sensibles d'un projet hors du code visible.

Token : Un token est un petit morceau de texte que l'IA compte pour mesurer ce qu'elle lit, écrit et facture.

Erreurs fréquentes

  • Coller une clé API dans un document public.
  • Réutiliser la même clé pour tous les outils.
  • Oublier de fixer une limite de dépense.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Tu branches Claude à n8n : n8n ne connaît pas ton compte complet, il utilise seulement la clé API que tu lui donnes.
  • Je garde en tête le piège principal : Coller une clé API dans un document public.
