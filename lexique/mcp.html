MCP

MCP, pour Model Context Protocol, c'est un standard qui permet à une IA de se brancher proprement sur tes outils et tes données. Au lieu de bricoler une connexion différente pour chaque service, tu ajoutes un serveur MCP qui expose les bonnes actions à l'agent. — Définition

MCP, en clair

En clair : c'est une prise standard pour les agents IA. Une fois branchés dessus, ils peuvent lire, chercher et agir dans tes vrais outils.

Ne confonds pas MCP avec le modèle IA lui-même : ce n'est pas un cerveau, c'est le câble qui le relie au reste de tes applications.

Exemple concret

Au lieu de bricoler une intégration différente pour chaque outil, tu ajoutes un serveur MCP qui expose les bonnes actions à l'agent.

Pourquoi ça compte

Les agents deviennent utiles quand ils peuvent lire, chercher et agir dans tes vrais outils.

Tu le croises dans Claude Desktop, Claude Code, Cursor et les connecteurs qui donnent accès à GitHub, Notion, fichiers ou bases.

À ne pas confondre

Tool use / Function calling : Le tool use permet à un modèle d'appeler un outil externe au lieu de seulement répondre avec du texte.

Workflow agentique : Un workflow agentique est une suite d'étapes où l'IA planifie, utilise des outils, vérifie et continue jusqu'au résultat.

Erreurs fréquentes

  • Installer trop de connecteurs sans savoir ce qu'ils autorisent.
  • Donner accès à des données sensibles sans garde-fou.
  • Confondre MCP et modèle IA.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.

Questions rapides

C'est quoi MCP en IA ?

MCP (Model Context Protocol) est un standard qui permet à une IA de se connecter proprement à des outils et des données via des serveurs MCP, plutôt qu'avec une intégration différente pour chaque service.

Où vais-je croiser MCP ?

Tu le croises dans Claude Desktop, Claude Code, Cursor et les connecteurs qui donnent accès à GitHub, Notion, fichiers ou bases.

Quel mot lire après MCP ?

Commence par Tool use / Function calling, Workflow agentique, Guardrail.
