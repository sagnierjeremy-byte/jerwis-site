— Définition

CLAUDE.md, en clair

En clair : c'est un mémo que tu écris une fois, et que Claude relit à chaque ouverture du projet pour enchaîner tes règles dès la première réponse.

Ne le confonds pas avec une doc technique : c'est une liste d'instructions actionnables, pas un roman, et surtout pas l'endroit où mettre tes clés API (ça, c'est le rôle du .env).

Exemple concret

Je note dans CLAUDE.md le stack du projet, le ton de voix, les commandes utiles : Claude lit ça en premier à chaque ouverture.

Pourquoi ça compte

Sans CLAUDE.md, Claude redécouvre le projet à chaque session. Avec, il enchaîne tes règles dès la première réponse.

Tu le vois à la racine d'un projet, dans les dossiers .claude, les tutos agents et les configurations partagées.

À ne pas confondre

Claude Code : Claude Code est l'agent de Claude qui lit un projet, modifie des fichiers et lance des commandes avec ton accord.

Skill & Agent : Un skill est une méthode réutilisable. Un agent est un système qui avance sur une mission avec outils, contexte et décisions.

Erreurs fréquentes

  • Écrire un roman au lieu d'instructions actionnables.
  • Y mettre des secrets (clés API, mots de passe) au lieu d'un .env.
  • Ne jamais le mettre à jour quand le projet évolue.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Je note dans CLAUDE.md le stack du projet, le ton de voix, les commandes utiles : Claude lit ça en premier à chaque ouverture.
  • Je garde en tête le piège principal : Écrire un roman au lieu d'instructions actionnables.

Questions rapides

C'est quoi CLAUDE.md en IA ?

CLAUDE.md est le fichier où tu notes les règles d'un projet (stack, ton de voix, commandes) pour que Claude Code les relise à chaque ouverture et n'ait pas à redécouvrir le projet. Il vit à la racine du projet.
