— Definition

What is
Claude Code?

In one sentence

Claude Code is Anthropic's coding agent, which turns the Claude AI into an agent able to read, write, and run code directly on your computer. You'll find it in the Code tab of the Claude app, on Mac and Windows. Instead of copy-pasting code out of a chat, you talk to it in plain language, and it acts inside your files, runs scripts, reads your codebase, tests, and fixes.

In concrete terms, you open the Claude app, click the Code tab, pick a folder on your computer, and you land in a session where Claude Code can do what a human assistant would do for you: open a file, edit it, run a test, validate, start over. You can tell it "Add a signup form to my page, hook it up to Resend, test that it works," and it chains the steps on its own.

Claude Code vs Claude.ai (the chat)

The chat is the conversation. You ask questions, Claude replies with text. Claude Code is the execution. You give it an intent, Claude reads your project, handles files, runs commands, and delivers a result. It's the same AI underneath (Anthropic's Opus, Sonnet, and Fable models), and both live in the same app, but the tab changes everything. In the chat you copy-paste code by hand; with Claude Code you never touch a programming keyboard again.

Claude Code vs Cursor, Aider, Codex, and GitHub Copilot

All these tools use an AI to write code. The difference plays out on three axes: where it lives (an app, an editor, or the command line), who acts (you vs the agent), and the model underneath (Claude vs GPT vs others). Cursor is a full code editor with a chat; Aider is an open-source command-line tool that edits files; GitHub Copilot is an autocomplete built into VS Code; Codex is OpenAI's coding agent. Claude Code combines Aider's simplicity, Codex's agency, and Claude's reasoning quality.

You'll find the detailed comparison table a bit further down this page. If you want the short version: go with Cursor if you want to replace VS Code, go with Claude Code if you want to hand off whole tasks to an autonomous agent.

Who is it for?

Officially, it's a tool for developers. In practice, I use Claude Code every day without being one. If you can install an app and write down what you want in plain language, you can use it. I know consultants who use it to generate client reports, marketers who build their landing pages with no dev, lawyers who automate contract review. The barrier to entry is lower than people think.

It all starts in the Claude app

In April 2026 Anthropic released a Claude Desktop app (Mac + Windows) with a built-in Code tab, zero commands to type. That's where this guide gets you started, in step 01, before the CLAUDE.md and the skills. The terminal version is still around, and I keep it for the curious in the appendix at the very bottom.

— The shift

Why Claude Code
changes everything.

The core idea

With Claude Code, the AI is no longer an assistant that suggests — it's an agent that executes. It's the jump from copilot to autopilot under your control. You give it an intent, Claude breaks it down, fires the right tools, checks the result, and hands you finished work.

For years, AI for code meant autocomplete: you type a function, the AI proposes what comes next, you accept. Useful, but you stay the pilot. Claude Code breaks that pattern. You describe what you want to get, and it picks the files to touch, the commands to run, the tests to write, all by itself. You go back to being the decision-maker, not the operator. That's what I call an agentic workflow.

What it changes for me, concretely

I built this site without writing a line of HTML myself. I built a sales tool I use every day. I have a Hermes Agent that automatically sends me Telegram messages when my builds pass. I launched a Gmail agent that filters my emails. All of it was built by Claude Code, and it's maintained by Claude Code.

Claude Code's real strengths

  • It reads your whole codebase. With 1 million tokens of context on Opus 5.5, it can hold an entire project in its head before acting.
  • It spins up subagents in parallel. You ask it to analyze five documents, it launches five at once, then synthesizes. Five times faster than a sequential agent.
  • It integrates through MCP. You can plug in Sanity, Stripe, Telegram, your Postgres database, your Meta Ads account — all through the open MCP standard.
  • You can control it finely. With hooks and the CLAUDE.md, you can stop Claude from touching certain files, impose rules on it, and trigger actions at specific moments.

What Claude Code does less well (the honest part)

I'm not going to sell you Claude Code as a miracle cure. Here's what it does less well in my experience: it sometimes invents library functions that don't exist (the context7 plugin fixes 80% of the problem by feeding it up-to-date docs). It over-writes code by adding pointless comments (the code-simplifier skill cleans that up). It sometimes loses the thread on very long sessions (past 500,000 tokens, I'd rather open a new session). And it doesn't replace a real senior dev for critical architecture decisions — for that, I ask a human.

My recurring use cases

  • I ask it to write my newsletters in my own voice (the copywriting skill)
  • I ask it to build web pages like this one (the landing-page-generator skill)
  • I have it audit the security of my projects (the security-review skill)
  • I have it do my research and curation (the deep-research skill)
  • I have it write and send cold emails (the cold-email skill)
  • I have it process my podcast audio and generate the transcripts
  • I have it watch my Vercel builds and alert me when there's a regression

All of this comes from skills. We'll cover how to install them in step 04 below.

— Step 01

Install the Claude app.
Everything starts there.

Claude Code lives in the Claude app, on Mac and on Windows. Nothing to copy-paste, nothing else to install: the app already includes Claude Code. You download it, sign in, and click the Code tab.

You need a paid plan

Claude Code isn't in Claude's free plan. It's included in Pro ($20 a month before tax, or $17 a month billed yearly), in Max (from $100 a month), and in the Team and Enterprise plans. If you click Code without a subscription, the app offers to upgrade you to a paid plan.

01

Download the app

Go to claude.com/download and pick your version. On Mac, it's the same one for Intel and Apple chips. On Windows, there's a standard version and one for PCs with an ARM processor.

02

Install it and sign in

On Mac, open the downloaded file and move Claude into your Applications folder. On Windows, run the installer. Open the app and sign in with your Claude account, the one with your subscription.

03

Click the Code tab

It's at the top of the app's sidebar. If the tabs only show icons, hover over them to see their names. If the app asks you to sign in again online, do it, then restart the app.

You're installed.

The Code tab is Claude Code. Everything else in this guide (your first session, the CLAUDE.md, the skills, the plugins) happens from there.

— Step 02

Your first session.

A session is a conversation with Claude about a folder on your computer. Claude works in the folder you give it. Start with a small test folder, it's the fastest way to see what it can do.

01

Create a test folder

On your desktop, right-click and create a new empty folder. Name it test-claude.

02

Open it in the Code tab

Look at the row just under the message box. The first button picks where Claude works, keep your computer (the Local group). The button next to it picks the folder. Click it, choose to open a folder, and select test-claude.

03

Pick your model and your mode

At the end of the same row is the model picker. Take Opus 5.5, the one Anthropic recommends to start with. Just before it, the mode selector sets what Claude can do without asking you. To start, keep the manual mode: Claude shows you every change and waits for your go-ahead.

04

Write your first message

Type in the message box, then press Enter: "Create a hello.txt file with 'Hello world' inside". Claude shows you the file it wants to create. Accept, then open your folder, hello.txt is there.

Next, try: "Make me a one-page website that presents my business, in an index.html file". And on a real project: "Explain in three sentences what this folder contains".

Review before you accept

When Claude has edited files, a small counter like +12 -1 shows up. Click it to see, file by file, what changed. You can comment on a line, and Claude reads your comment and fixes it. You can also redirect it at any time: type your correction and press Enter, even while it's working.

The other modes, later

Once you're comfortable, try the mode that accepts file edits on its own, or Auto mode, where a safeguard checks every action in the background and blocks the risky ones. Plan mode has Claude propose a plan before it touches anything.

— Level up

The official plugins worth knowing.

Anthropic offers more than 140 official plugins on its marketplace (the official "app store", at claude.com/plugins). A plugin is a ready-made pack of skills, commands, and agents that installs in a few clicks from the app. Nothing to configure, nothing to copy by hand. Installed for you, it's available in all your projects.

After several weeks of testing, here are the 6 I use. Each one adds real value for a non-dev running concrete projects.

Install the 6 from the app

In a Code tab session, click the + next to the message box, then Plugins, and open the plugin list. Search for each of the six by name (superpowers, context7, claude-md-management, frontend-design, code-review, code-simplifier) and install it for yourself, so it works across all your projects. Then open a new session, and the new commands show up when you type / in the message box. In the terminal version, it's six commands, and they're in the appendix.

What they bring

01

superpowers — A full dev methodology

14 skills + 3 slash commands (the shortcuts that start with /) — /brainstorm, /write-plan, /execute-plan. It forces Claude to spec before coding, to do TDD (Test-Driven Development · "write the test first, the code second"), and to review. Type /brainstorm in the message box with an article idea or a feature, and you'll see the difference.

02

context7 — Up-to-date docs for any framework (the technical "skeleton" a site/app is built on, e.g. Next.js, React)

An MCP server (a standardized connector between Claude and an external service) that fetches (downloads) the current official documentation on demand. Claude won't answer you about the Next.js version from 2 years ago anymore. Essential the moment you touch a recent framework (Next.js 16, Supabase, Stripe, Resend v3).

03

claude-md-management — Automatic audit of your CLAUDE.md

The /revise-claude-md command. Run it in a project, Claude audits your CLAUDE.md and suggests concrete improvements (what's missing, what's outdated, what deserves to be more precise). I run it once a month across my 5 main projects.

04

frontend-design — Production-grade UI without a verbose brief

A skill that fires on its own the moment you work on a page or a component. It generates distinctive interfaces and avoids generic AI designs. Useful when you redo a section of the site or build a landing page.

05

code-review — Multi-agent review before commit

The /code-review command. Several specialized agents run over your diff (the list of changes made since the last save): security, perf, readability. Each one filters by confidence. Less verbose than a human review, but it catches the dumb oversights.

06

code-simplifier — Cleans up what Claude over-generated

An agent that simplifies recently modified code. Useful when Claude wrote 400 lines for a function that deserved 100. You ask it to "simplify," it trims down without breaking the behavior.

How it fits into the day to day

You don't launch them one by one. They fire on their own when their domain is recognized. The slash commands (/brainstorm, /revise-claude-md, /code-review) are one-off tools you call on demand. Everything else is automatic.

To understand the difference between a plugin, a marketplace, a skill, and an agent in plain words, check out entry #08 in the glossary.

— Not working?

Quick troubleshooting.

The Code tab offers to upgrade me to a paid plan

Claude Code isn't in the free plan. Get Pro or Max at claude.com/pricing, then come back to the app.

The app asks me to sign in online

Finish signing in on the page that opens, then restart the app. The Code tab then opens normally.

Claude isn't loading my skills

Open a new session and type / in the message box, your skills should show up in the list. If not, ask Claude: "List the folders in .claude/skills, in my home folder". If the folder is empty, redo step 04.

Claude isn't reading my CLAUDE.md

Ask it: "Show me the contents of my global CLAUDE.md, in the .claude folder of my home folder". If it shows it to you, you're good, it reads it at every session. For a project, the CLAUDE.md has to sit at the root of the folder you opened.

— Glossary

The vocabulary
of Claude Code.

Before diving deeper, here are the terms that come up all the time. Short definitions, with a link to the full entry in my AI glossary.

  • Claude Code Anthropic's coding agent, in the Code tab of the Claude app. It acts inside your files for you. See the entry →
  • CLAUDE.md A context file at a project's root or in ~/.claude/, read by Claude at every session. See the entry →
  • Skill A folder of instructions that turns Claude into a specialist for a job (cold-email, copywriting, security-review). See the entry →
  • Subagent A mini-Claude the main agent launches for a parallel task. See the entry →
  • Hook A script that fires automatically on a Claude Code event (before a tool, after a response, on stop). See the entry →
  • Slash command A manual shortcut starting with /, typed in the message box, e.g. /brainstorm, to launch a specific workflow. See the entry →
  • MCP Model Context Protocol, the open standard for plugging Claude into external services (DB, API, tools). See the entry →
  • Agentic workflow A pattern where the AI chains several steps autonomously, using its tools with no human involvement. See the entry →
  • Context engineering The art of building the right context (files, examples, rules) so the AI produces the right answer. See the entry →
  • Tool use A model's ability to call external tools (bash, file, web). The heart of agency. See the entry →
  • Context window The number of tokens the model can hold in its head at once. Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1 each hold 1 M. See the entry →
  • Hallucination When the AI invents a function or a fact that doesn't exist. Enemy number one of agents. See the entry →
  • API key An access card that lets a program talk to a paid third-party service. Keep it secret. See the entry →
  • .env file A local file that holds your secrets (API keys, DB passwords). Never to be committed to Git. See the entry →
  • GitHub Actions GitHub's built-in CI/CD system. You can run Claude Code there in non-interactive mode on events. See the entry →

— Full FAQ

Everything people ask me
about Claude Code.

Twenty questions I get by email or DM every week. Direct answers, in first person, with no marketing pose.

What is Claude Code in one sentence?

Claude Code is Anthropic's coding agent, which turns the Claude AI into an assistant able to write, edit, run, and debug code directly on your computer. You open it in the Code tab of the Claude app, on Mac or Windows. Instead of copy-pasting code out of a chat, you talk to it, and it acts inside your files.

How much does Claude Code cost in 2026?

Claude Code is included in the Claude Pro plan at $20 a month before tax ($17 a month billed yearly) and in Claude Max, from $100 a month. The free plan doesn't include it. In the terminal version (see the appendix), you can also pay as you go with an Anthropic API key. Opus 5.5 then costs $4 per million input tokens and $20 per million output tokens.

For regular daily use, the Pro plan stays the most cost-effective option. Max becomes worth it when you hit Pro's limits every week, or if you want Fable 5.1, the most powerful model, included in Max.

Do you have to be a developer to use Claude Code?

No. I'm neither a developer nor a coder, and I use it every day to write newsletters, build landing pages, and automate tasks. Claude Code reads your intent in plain language and does the technical work for you.

All you need is to install the Claude app and describe what you want, like in a message. Nothing to type in a command line, it all happens in the Code tab.

Claude Code vs Cursor: which one should you pick?

Cursor is a code editor (a fork of VS Code) with AI autocomplete and a built-in chat. Claude Code is an autonomous agent that runs tasks on your computer, from the Code tab of the Claude app. If you want to replace VS Code and keep control line by line, go with Cursor. If you want to hand off whole tasks to an agent that reads, writes, and tests for you, go with Claude Code.

My usage: Claude Code as the main tool for heavy tasks, Cursor on the side when I want to see the diff live. Both cost $20/mo, you can try both.

Claude Code vs Codex (OpenAI): what are the differences?

Codex runs on OpenAI's GPT models (GPT-6.1 Sol today). Claude Code runs on Anthropic's Claude models (Opus 5.5, Sonnet 5.5, Fable 5.1). In my experience, Claude is better at understanding an existing codebase and reasoning over long context. Codex is often faster on short, creative tasks.

The choice mostly comes down to the ecosystem you already live in. If you have ChatGPT Plus ($20/mo) or a higher plan, Codex is included and you have nothing to add. If you want maximum reasoning quality, Claude Code stays my pick.

How do you install Claude Code?

Download the Claude app from claude.com/download, install it on your Mac or Windows PC, and sign in with a paid plan (Pro or higher). Click the Code tab, pick a folder on your computer, and you're set. Nothing to type in a command line.

The step-by-step is higher up on this page, with troubleshooting and CLAUDE.md setup. Allow 20 minutes the first time. If you'd rather use the terminal version, it's in the appendix at the very bottom.

Which operating systems does Claude Code run on?

The Claude app and its Code tab run on macOS (Intel and Apple Silicon) and on Windows, and a Linux version is in beta. That's the simplest route, and the one this guide follows.

The terminal version also runs on macOS, Linux, and Windows, natively or through WSL. It's covered in the appendix at the bottom of the page.

How does Claude Code handle my secrets and .env files?

Claude Code reads the contents of the files you ask it to read. If you ask it to open a .env file, it will see it.

Best practices: add .env to your .gitignore, never explicitly open the file in your prompts, and use the security-review skill before every commit so it checks that no key has been left in plain text in the code. You can also configure a hook that blocks any write to .env files.

Can Claude Code access the internet?

Yes, through several built-in tools. WebFetch reads a specific web page, WebSearch runs a search, and the context7 plugin fetches up-to-date official framework documentation.

In my experience, it's essential the moment you work on a stack that moves fast (Next.js, Tailwind, Stripe). Without internet access, Claude risks answering you about the version from 18 months ago.

Can Claude Code work on several files in parallel?

Yes. It's actually one of its superpowers. Claude Code spins up subagents in parallel when the task allows it. You ask it to analyze five documents, it launches five agents at once, then synthesizes. You ask it to edit several related files, it opens them in parallel.

To go further, read my article Claude Code loops, explained, which breaks down the execution machinery.

What is Claude Code's token context?

The four Claude models of November 2026 (Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1) all have 1 million tokens of context.

In practice, that means Claude Code can read an entire codebase of tens of thousands of lines without losing the thread. For comparison: this site is about 50,000 tokens if you take all the HTML files, so it fits entirely within the context of a single session.

How do you use MCP with Claude Code?

MCP (Model Context Protocol) is an open standard that lets Claude Code connect to external services: databases, Sanity, Stripe, Telegram, any CRM.

In the Claude app, you click the + next to the message box and open the connectors to plug the service in with a few clicks. The ones not in the list go into a settings file (for example .mcp.json at the project root), which Claude can write for you. Claude Code can then call it like any native tool. Many providers now offer an official MCP server.

Skills vs slash commands: what's the difference?

A skill is a folder of instructions that fires automatically when Claude recognizes the domain of your request. Example: the cold-email skill loads on its own when you write "write a B2B cold email."

A slash command is a manual shortcut you type in the message box (example: /brainstorm) to launch a specific workflow. Skills are automatic, slash commands are deliberate. The two can coexist: a slash command can call a skill.

How do you version my Claude Code commands in Git?

Your ~/.claude/ folder holds your global CLAUDE.md, your skills, your hooks, and your settings. You can track it in a private Git repo to share your setup across several machines.

For a project, the local CLAUDE.md and the .claude/ folder live at the root and get committed with the code. That's what lets a new teammate (human or AI) pick up the project context without asking all the questions again.

Claude Code hooks: what are they for?

Hooks are scripts that fire automatically on specific events: before a response, after a tool call, when a session stops.

In practice, you can wire up a Telegram notification at the end of a long task (so your phone buzzes when the build is done), block Claude from touching certain sensitive files, or trigger a security audit before every commit. That's what separates an out-of-the-box Claude Code from one tuned to your workflow.

Claude Code's Plan Mode: when should you use it?

Plan Mode forces Claude to lay out its plan of action before acting. In the app, you pick Plan in the mode selector, under the message box.

It's useful the moment a task spans more than three files or touches a database. You approve the plan or fix it before a single file is touched. My reflex: Plan Mode is mandatory the moment there's a risk of breaking something, or when the task could go the wrong way if Claude misreads what I mean.

Can you run Claude Code in GitHub Actions or CI?

Yes. Anthropic offers an official GitHub Actions integration. You trigger Claude Code on an event (pull request, push, issue), it does its task in non-interactive mode and commits the result.

Handy for automating code reviews, audits, documentation, or release notes. It needs an Anthropic API key stored as a GitHub secret. To dig in, see the GitHub Actions glossary entry.

Data privacy: does Anthropic keep my code?

By default, Anthropic doesn't retain your data to train its models if you're on a Pro or API account. Claude Code conversations may be stored for 30 days for abuse moderation, then deleted.

For enterprise use with sensitive data, the Zero Data Retention option exists on Enterprise accounts. If you work on confidential client code, that's the option to ask your Anthropic sales contact about.

What are Claude Code's known limits in 2026?

Three limits I run into regularly:

1. It sometimes invents library functions that don't exist (use the context7 plugin to feed it up-to-date docs, which fixes 80% of the problem).

2. It tends to over-write code by adding too many comments (the code-simplifier skill fixes that).

3. It can lose the thread on very long sessions (past 500,000 tokens, I open a new session). And one human limit: Claude Code doesn't replace a senior dev for critical architecture decisions.

Which Claude model should you use: Opus, Sonnet, or Fable?

In November 2026, Opus 5.5 is the model Anthropic recommends to start with, very strong at code and agents, and included in Pro. Sonnet 5.5 is the best balance of speed and intelligence. Haiku 5.5 is the fastest and cheapest, for sorting or extracting lots of text. Fable 5.1 is the most powerful, best kept for the hard cases. It's included in Max (up to half of the weekly limit) and paid with usage credits on Pro.

Anthropic recommends starting with Opus 5.5 and moving to Fable 5.1 only if that isn't enough. You can switch models whenever you like, even mid-session, with the model picker at the end of the row under the message box. To compare in detail, check out the AI models page.

— Appendix

For the curious:
the terminal version.

Everything above happens in the app. Claude Code also exists as a command-line tool, in the terminal. It's the original version, the one the first edition of this guide used. Same engine, same settings: your CLAUDE.md, your skills, your hooks, and your MCP servers work in both, and you can use both on the same project.

It's mostly useful for what the app doesn't do, like script mode (claude -p), agent teams, or pay-as-you-go billing with an Anthropic API key.

Not needed to get started

If you're just starting, you can stop before this appendix, the whole guide works in the app. What follows is for people who like to look under the hood.

The terminal I use, Ghostty (optional)

Ghostty is the terminal I use on Mac. It's free, fast, good-looking, and it supports emoji. You don't have to install it, the macOS Terminal (already there, search "Terminal" in Spotlight) does the job perfectly.

01

Download Ghostty

Go to ghostty.org and click "Download". It's free, no email required.

02

Install the app

Double-click the downloaded .dmg file, drag Ghostty into your Applications folder. Open it. macOS will ask whether you trust it, click "Yes".

03

Check that it works

With Ghostty open, type this command and hit Enter:

echo "Salut Ghostty"

If you see Salut Ghostty print out, you're ready for the next step.

Install Claude Code on the command line

Open your terminal (Ghostty or Terminal) and paste the official command. On Mac or Linux:

curl -fsSL https://claude.ai/install.sh | bash

On Windows, in PowerShell:

irm https://claude.ai/install.ps1 | iex

Why this command?

It downloads Anthropic's official script and runs it. It installs Claude Code on your system. You can read the script before running it if that reassures you, it's the link inside the command.

01

Run the command

Paste it into your terminal, hit Enter, and wait for it to finish. It shows no progress while it downloads, that's normal.

02

Restart your terminal

Quit the terminal fully (Cmd+Q on Mac) and reopen it, so the new claude command gets picked up. Then check:

claude --version

You should see a version number, for example 2.1.211 (Claude Code).

03

Connect your Claude account

Type:

claude

The first time, it opens your browser so you can sign in. You need the same paid plan as for the app, or an Anthropic API account. It takes 30 seconds.

04

Test it

Create an empty folder on your desktop, open it in the terminal, and launch Claude:

mkdir ~/Desktop/test-claude
cd ~/Desktop/test-claude
claude

Ask it something like: "Create a hello.txt file with 'Hello world' inside". You'll see it create the file all by itself.

The same setup, as commands

What the app does for you above, here's the typed version.

Drop in the global CLAUDE.md

mkdir -p ~/.claude
cp ~/Downloads/CLAUDE.md ~/.claude/CLAUDE.md
open ~/.claude/CLAUDE.md

Install the pack's 26 skills

mkdir -p ~/.claude/skills
cp -R ~/Downloads/jeremy-claude-pack/skills/* ~/.claude/skills/

Install the 6 plugins

claude plugin install superpowers
claude plugin install context7
claude plugin install claude-md-management
claude plugin install frontend-design
claude plugin install code-review
claude plugin install code-simplifier

Then restart Claude Code. Inside a session, the /plugin command also opens the plugin manager.

Model, Plan Mode, and autopilot

/model switches models mid-session. Shift+Tab cycles through the modes, including Plan Mode. And claude --dangerously-skip-permissions starts a session with no permission prompts at all, best kept for separate Git worktrees. It's the equivalent of the app's bypass permissions mode.

Troubleshooting the terminal version

The claude command isn't recognized

Open a new terminal window. If that changes nothing on Mac, add Claude Code's folder to your PATH:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

For a full check of your install, run claude doctor.

Claude isn't loading my skills

ls ~/.claude/skills/

You should see the list of skills. If the folder is empty, redo the copy above.

Claude isn't reading my CLAUDE.md

cat ~/.claude/CLAUDE.md

If it prints content, you're good. Claude reads it automatically at every session.

Switching between the two

A session started in the terminal can carry on in the app. Type /desktop in the session and it opens in the Code tab (on Mac and Windows, with a Claude subscription). The other way around, close the terminal session, then type /resume in the app's message box.

Back to the app

If you just want to move forward, the rest of the guide works without a single command line. Back to step 01.
